# Git & GitHub Unit — One-Page Student Summary

**Course:** Full-Stack Web and AI Application Development

---

## What This Unit Is About

You will use **GitHub** to prove **how you learn** — not just to hand in files.

**Your repo:** `YourName-Full-Stack-Web-and-AI-Application-Development`

---

## How Every Class Works (45 Minutes)

1. **Skill Warm-up** — one assigned GitHub video
2. **Talk Robin 1** — pair talk
3. **Entry Check** — quick questions on your own
4. **Core Pattern** — learn today’s pattern
5. **Guided Practice** — one task with teacher help
6. **Independent Rebuild** — continue that task
7. **Talk Robin 2 + Evidence** — add today’s learning-log entry

There is no video homework. If today’s `learning-log.md` entry is not committed
before class ends, finishing that entry is the only homework.

## What Success Looks Like

- Clear README and one maintained `learning-log.md`
- A visible sequence of commits with meaningful messages
- You can explain commits and history **orally**
- You debug before asking for help
- You submit Exit Evidence every lesson

---

## What Does NOT Count as Success

- Watching videos without rebuilding
- Copy-pasting README from AI without understanding
- One commit called `final` at the end
- Leaving the learning log blank

---

## Mastery Levels (Target: Level 3+)

0 Exposure → 1 Copy → 2 Explain looking → **3 Rebuild checklist** → 4 Rebuild blind → 5 Modify/debug/help

---

## Key Principles

- Watching ≠ mastery. Copying ≠ mastery.
- Debugging is learning, not failure.
- AI can hint — **you** must understand and revise.
- Evidence: GitHub commits, screenshots, learning log, reflections.
