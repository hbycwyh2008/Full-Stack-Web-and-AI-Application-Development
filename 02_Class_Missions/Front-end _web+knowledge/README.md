# Front-end _web+knowledge — Class Missions

**Goal:** Continue the portfolio pathway from HTML/CSS practice to JavaScript and React.

> **Before this block:** complete [`Phase_1_Notion_Portfolio/`](../Phase_1_Notion_Portfolio/) and [`Phase_2_Web_Basics/`](../Phase_2_Web_Basics/) (MDN first form).

This folder combines three connected learning blocks:

1. **HTML/CSS** — build a digital business card
2. **JavaScript** — add interaction and logic
3. **React** — rebuild the portfolio as reusable components

Students should keep using the same GitHub repository:

```text
[studentName]-Full-Stack-Web-and-AI-Application
```

Notion is the public showcase. GitHub is the evidence and revision history.

---

## Course Sequence

| Block | File | Suggested time | Main evidence |
|---|---|---:|---|
| 1 | [module-02-html-css-digital-business-card.md](module-02-html-css-digital-business-card.md) | 6 classes | HTML/CSS digital business card |
| 2 | [module-03-javascript-interactive-profile.md](module-03-javascript-interactive-profile.md) | 8–10 classes | Interactive profile page |
| 3 | [module-04-react-component-portfolio.md](module-04-react-component-portfolio.md) | 8–10 classes | Component-based React portfolio |

Each class is assumed to be **90 minutes**.

Fast track total: about **16 classes**.
Recommended total: about **24–28 classes**.
Zero-background total: about **32 classes**.

---

## Classroom Learning Cycle

Each class should still follow the same classroom model:

```text
individual learning → Talk Robin / group discussion → group answer → Entry Points Check → teacher explains only what students do not understand → mission task → exit check → submission of evidence
```

Do not make these blocks teacher-demo-first. Students should watch, practice, discuss, rebuild, explain, and submit evidence.

---

## Final Outcome

By the end of this folder, students should have:

1. A digital business card made with HTML/CSS
2. A JavaScript-enhanced profile page
3. A React portfolio built from components
4. GitHub evidence for all three blocks
5. Notion portfolio updated with frontend project links
6. Reflections explaining what changed from no-code to code-based portfolio building

---

## Teacher Pacing Note

If the course schedule is short, keep the required product simple:

```text
MDN first form (Phase_2_Web_Basics) → HTML/CSS card → JavaScript interaction → React component rebuild
```

Do not add extra frameworks before students can explain HTML structure, CSS styling, JavaScript behavior, and React components in their own words.
