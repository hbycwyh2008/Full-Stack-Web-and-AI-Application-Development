# Lesson 2: Matrices as Tables and Images

## Goal

Understand a **matrix** as a table of numbers.

## Key Ideas

- A matrix is a table of numbers (rows and columns).
- A dataset can be a matrix.
- A grayscale image can be a 2D matrix.
- An RGB image can be a 3D array (height × width × channels).

## Example

```text
X = student data matrix
rows = students
columns = features (subjects, age, etc.)
```

## Activities

1. Draw a small 3×4 matrix; label rows and columns.
2. Optional: DeepLearning.AI Week 3 intro (selected parts).
3. Write `matrix-notes.md`.
