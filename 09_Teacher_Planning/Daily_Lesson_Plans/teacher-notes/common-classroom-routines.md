# Common Classroom Routines

Reusable routines across daily lesson plans.

---

## Start of Class (2 min)

- Display today’s Skill Warm-up resource (Coursera URL + exact clip title).
- Reminder: “Evidence due in Talk Robin 2 + Evidence.”

---

## Skill Warm-up Routine

- One Coursera clip / reading / short task only (3–8 min of attention)
- Students write: “I saw ___ / I’m unsure about ___”
- Do not assign finishing the whole Coursera course in class

---

## Talk Robin 1 Routine

1. Assign pairs (clock partners, row pairs, or random).
2. Display timer: 45s → 45s → 30s.
3. Display prompts: what was done / what was confusing.
4. Cold call 2–3 students: “What did your pair agree was confusing?”
5. Record one common confusion on board for Core Pattern.

---

## Entry Check Routine

- Comes **after** Talk Robin 1 (poster order)
- Individual work — no devices talking to neighbors
- Questions on paper or LMS — not graded for perfection, graded for attempt
- Teacher scans answers while students finish — decide how deep Core Pattern needs to go

---

## Talk Robin 2 Routine

1. Assign pairs (clock partners, row pairs, or random).
2. Display timer: 45s → 45s → 30s.
3. Display prompts on slide (summarize / explain / evidence).
4. Cold call 2–3 students: “What did your pair agree on?”
5. Move to Exit Evidence submission.

---

## Independent Rebuild Routine

- Distribute checklist on slide — students self-check
- Teacher circulates with question: “What step are you on? What did you try?”
- No full solutions on board during this block
- Level 4+ students: optional peer coach role (hints only)

---

## Exit Evidence Routine (40–45 min)

- Display submission checklist in the final 5 minutes
- Students submit link + screenshots + sentences before leaving
- 1–2 oral cold calls if time
- “Not submitted = incomplete until teacher deadline”

---

## Oral Explanation Cold Call

Sample questions:

- “What did your last commit change?”
- “Read your commit message — why is it better than `update`?”
- “If GitHub looks old, what do you check first?”

If student used AI: “What did you change after AI?”

---

## Device / Auth Failures

- Pair student with working auth for **Guided** only — they still must **Independent Rebuild** on web editor
- PAT setup station for Lesson 5
- Web fallback documented in Lesson 5 plan

---

## Finish-Up Policy

- No heavy homework if class work complete
- Incomplete Exit Evidence → finish by teacher deadline (not optional long assignments)
- One meaningful commit + screenshot minimum for finish-up
