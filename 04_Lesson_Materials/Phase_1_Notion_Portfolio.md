# Phase 1: Notion Portfolio

## Phase Goal
Build a public-facing portfolio website in Notion and start a habit of documenting your work.

## Key Concepts
- What a portfolio is and why it matters for school and career.
- How to organize information clearly for a reader.
- The difference between public showcase (Notion) and technical evidence (GitHub).

## Required Student Output
- A published Notion portfolio with: Home, About Me, Projects, Skills, Certificates, Learning Notes, GitHub / Contact.
- At least one draft project page for the AI School Assistant.

---

## Lesson Sequence

This phase runs over about two lessons (one week standard pace).

| Lesson | Focus |
|---|---|
| 1.1 | Set up Notion + page structure |
| 1.2 | Fill content, add project page, publish |

---

## Lesson 1.1 — Setting Up the Portfolio

**Lesson Goals:** Create a Notion account and build the seven-section structure.

- **Warm-up (5 min):** Show two portfolios (one messy, one clear). "Which would you trust more, and why?"
- **Mini Lesson (15 min):** Tour the teacher's sample portfolio. Explain each of the seven sections.
- **Guided Practice (20 min):** Students create their Notion page and add the seven section headings using `01_Student_Templates/Student_Portfolio_Template.md`.
- **Independent Work (10 min):** Fill in Home and About Me.
- **Exit Ticket:** Name the seven sections of your portfolio.
- **Homework:** Complete Home, About Me, and Skills sections.

---

## Lesson 1.2 — Content, Projects, and Publishing

**Lesson Goals:** Add a project page, add AI literacy notes, and publish.

- **Warm-up (5 min):** "What is one project or skill you are proud of?"
- **Mini Lesson (10 min):** What makes a strong project page (problem, tools, what you learned).
- **Guided Practice (20 min):** Create a draft AI School Assistant project page using the project page fields.
- **Independent Work (15 min):** Add Phase 0 AI literacy notes to Learning Notes. Publish the page.
- **Exit Ticket:** Paste your public Notion link.
- **Homework:** Polish all sections; make sure the public link works.

---

## Submission Requirements
- [ ] Public Notion link shared.
- [ ] All seven sections present.
- [ ] AI literacy notes added to Learning Notes.
- [ ] One draft AI School Assistant project page.

## Common Student Problems
- Forgetting to publish / share settings → walk through "Share → Publish" together.
- Empty sections → require at least one line in every section.
- Over-designing instead of writing content → remind: clarity over decoration.

## Teacher Notes
> 先展示示范，再让学生模仿。Show the sample first, then let students mirror it. Keep the focus on clear writing, not visual polish. This portfolio will hold every future project, so set good habits now.

## AI Lens Reflection
Ask students: *"How will you describe your AI usage on each project page so a reader trusts your work?"* Add a short note to the Learning Notes section.
