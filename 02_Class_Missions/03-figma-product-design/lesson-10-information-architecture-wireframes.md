# Lesson 10 — Information Architecture and Low-Fidelity Wireframes

## Mission
Decide what information belongs where before spending time on visual polish.

## Core Artifact
Sitemap / information architecture + low-fidelity wireframes.

## Launch Challenge — 0–10
Card-sort a set of page content into groups and labels. Compare how different students organize the same information.

## Evidence / Resource Scan — 10–25
Inspect two wireframe examples. Annotate hierarchy, navigation, primary action, secondary action, and feedback areas.

## Team Sensemaking — 25–40
Teams reconcile card-sort differences and choose an information architecture. Record one label or grouping that was difficult and why.

## Studio Build — 40–65
Create low-fidelity wireframes for the primary flow. Use grayscale/basic shapes; focus on hierarchy, sequence, controls, content, error states, and mobile/desktop structure rather than decoration.

## Critique / Test — 65–80
Run a “five-second hierarchy test” and a task walkthrough with another team. Reviewers point to what they think is clickable and what they would do first.

## Ship Evidence — 80–90
Revise the wireframe and capture before/after evidence.

## Success Evidence
A user can understand the page purpose and primary path without high-fidelity styling.
