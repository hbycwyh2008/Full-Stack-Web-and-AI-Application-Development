# Git & GitHub Workflow Poster Series

Bilingual (English + 中文) classroom posters focused on the **Git workflow as a process**, not isolated command memorization.

## Poster Set

1. **Git Workflow Overview / Git 工作流总览**
   - Working Directory → Staging Area → Local Repository → Remote Repository → Sync Updates
   - Focus: where changes move and why each step exists.

2. **Branching and Collaboration / 分支与协作**
   - Create branch → work → push → Pull Request → review → merge → update local `main`
   - Focus: safe team collaboration and keeping `main` stable.

3. **Essential Git Commands / 常用 Git 命令**
   - Quick classroom reference for the commands used in the workflow.
   - Focus: commands as tools inside the workflow, not as a standalone memorization list.

## Recommended Classroom Use

- Teach **Poster 1** first to establish the mental model.
- Use **Poster 2** when introducing branches, Pull Requests, review, and merge.
- Keep **Poster 3** available as a classroom cheat sheet during practice.
