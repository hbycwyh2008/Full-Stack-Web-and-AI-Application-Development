## Lesson Goal

After watching the official video, students can explain how Git records snapshots and why version history is safer than keeping many copies of the same file.

This lesson uses **one video and one guided practice**. Do not re-teach the Classroom Flow posters and do not assign another playlist video as homework.

### 0–10 min: Skill Warm-up

Watch **playlist #1 only**: [A brief introduction to Git for beginners](https://www.youtube.com/watch?v=r8jQ9hVA2qs).

While watching, record:

- One new term
- One action demonstrated
- One question to test during practice

### 10–13 min: Talk Robin 1

- **A:** “The video's main idea is…”
- **B:** “A step I need to remember is…”

### 13–17 min: Entry Check

1. How do you currently keep earlier versions of a file?
2. What problem happens when many copies are named `final`?
3. What do you think version control records?

### 17–21 min: Core Pattern

Teacher demonstrates the task once and points out where students can verify the result. Students identify the action, the artifact, and the evidence before beginning.

### 21–32 min: Guided Practice

1. Without replaying the video, create a local file named `01-git-introduction.md`.
2. Save three copies of one sentence as `draft-1`, `draft-2`, and `final`, then list what is hard about this manual method.
3. Replace the copies with one short timeline that labels three changes as snapshots.
4. Explain in two sentences how Git improves this process. Keep the file for the Lesson 4 upload.

### 32–40 min: Independent Rebuild

Close the video and notes. Rebuild the snapshot timeline with a different example. Include three snapshots and explain why one tracked history is better than several files named `final`. Save this second example locally for Lesson 4.

### 40–45 min: Talk Robin 2 + Evidence

Show the local note and explain the difference between a manual file copy and a Git snapshot.

Add to `learning-log.md`:

```markdown
## Lesson 1
- What I did:
- What I learned:
- What was hard:
- Evidence link:
```

Save the Lesson 1 learning-log entry locally. It will be added to the course repository in Lesson 3. **Homework is only the unfinished learning-log entry; no video homework.**

## Common Mistakes

- Watching or assigning a second playlist video
- Completing clicks without checking the resulting artifact
- Using vague commit messages such as `update`
- Publishing passwords, tokens, recovery codes, or other private information
- Treating a screenshot as a substitute for repository evidence
