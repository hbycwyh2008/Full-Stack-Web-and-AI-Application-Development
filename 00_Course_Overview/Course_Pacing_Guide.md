# Course Pacing Guide — Stable Lesson Anchors, Flexible Meetings

All meetings are approximately **45 minutes**. The 00–32 lesson identifiers are retained, but each theme may need multiple meetings. The older 33-session estimate is not a cap. Use the [current teaching plan](Current_Teaching_Plan.md) and mastery evidence to schedule.

| Lesson anchors | Focus | Pacing decision |
|---|---|---|
| Required orientation + 00–01 | Posters, CS identity, computational thinking, lifecycle | Keep existing prerequisite work |
| GitHub Foundations | Repository, branches, commits, PR/review, history | Follow the existing foundation unit |
| 05–08 | HCI needfinding, evidence/bias, alternatives | Continue existing lessons |
| 09–11 + skill labs | Selected Coursera Figma, skill Quiz/practical, two evaluation methods, Skill Board, own prototype revision/retest | Add focused skill/assessment and participant-testing meetings; do not fit all into three classes |
| 12–15 | HTML/CSS from the tested design; HKUST M1 support | Guided practice + independent rebuild |
| 16–20 + game practice | HKUST JS foundations, Guessing Game, Canvas/Ping Pong/Collect the Square | Add prerequisite teaching and project practice before progressing |
| 21–24 | Six-theme foundation AI literacy block | Initially six meetings; extra support as needed; twelve-meeting reading route optional |
| 25–26 | Usability, QA, release and maintenance | Preserve evidence/fix/retest cycle |
| 27–32 | Independent capstone lifecycle | Schedule design/build/test/release gates |

Do not equate Coursera estimated hours with video duration or local class meetings. Keep L09 low-fi testing early; advanced Figma skills can be checked later. Teach privacy/disclosure/verification before any AI-assisted coding.

## Lesson 00 Classroom Flow

Lesson 00 uses the canonical **45-minute seven-block flow**:

- 0–5: Skill Warm-up — Khan Academy CS foundation excerpt;
- 5–9: Talk Robin 1 — discuss what CS is and what remains unclear;
- 9–14: Entry Check — whole-class CS share and misconception diagnosis;
- 14–24: Core Pattern — correct the CS definition, connect CS to problem
  solving, then watch the 4:31 computational-thinking follow-up;
- 24–32: Guided Practice — solve the shared laptop-distribution problem;
- 32–40: Independent Rebuild — apply, test, and refine the process independently;
- 40–45: Talk Robin 2 + Evidence — explain, reflect, and submit proof.

The previously completed AP CSP explanation is not repeated in Lesson 00.

## AI Literacy Placement

Default: teach the [six-theme foundation path](../02_Class_Missions/06-ai-literacy/foundation-path.md) as a coherent L21–L24 unit. Reading begins and ends in class. No required pre-class reading or full-chapter homework. Responsible-use habits run throughout development; the six themes are not automatically converted into a 15-minute lecture at the start of every coding lesson.

The teacher can deliberately choose a parallel timetable when appropriate. The earlier twelve-meeting book route is optional depth, not additional compulsory work. Do not copy the ASC eight-session plan into the foundation class.

## If Time Is Short

**Do not cut:** CS orientation, GitHub core workflow, bias-aware research/synthesis, Figma prototype/testing, JavaScript fundamentals, AI literacy core, usability testing, capstone release/retrospective.

**Cut first:** optional Python, optional AI API work, legacy framework units, extra portfolio/certification work.

## If Time Remains

Prefer a deeper second design/build iteration, then optional Python or a small evaluated AI-application extension.
