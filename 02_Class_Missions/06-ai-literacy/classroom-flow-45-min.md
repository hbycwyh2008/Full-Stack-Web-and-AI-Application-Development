# AI Literacy — 45-Minute Classroom Flow

**Length:** 45 minutes per meeting.  
**Block names:** use **only** the poster names from [../shared/classroom-flow.md](../shared/classroom-flow.md). Do not invent alternate titles.

```text
Skill Warm-up → Talk Robin 1 → Entry Check → Core Pattern
→ Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence
```

## Timing (same as course poster)

| Time | Block | AI Literacy activity |
|---|---|---|
| **0–5 min** | **Skill Warm-up** | Meet today’s Mitchell idea: short prediction task **or** teacher posts exact page range and opens the first lines |
| **5–9 min** | **Talk Robin 1** | Pair: what the warm-up asked / what is confusing before deep reading |
| **9–14 min** | **Entry Check** | Individual: one claim or judgement line before the main passage work |
| **14–19 min** | **Core Pattern** | Teacher names today’s reading pattern (C / E / ? ; claim–boundary) — micro only |
| **19–30 min** | **Guided Practice** | Read assigned chunk(s) with marking; teacher coaches evidence use |
| **30–40 min** | **Independent Rebuild** | Finish organizer / transfer item alone |
| **40–45 min** | **Talk Robin 2 + Evidence** | Summarize; submit Learning Log + named artifact |
