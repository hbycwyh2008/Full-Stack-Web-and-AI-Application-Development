# Classroom Flow — Canonical 45-Minute Structure

**Every class in this course is designed for 45 minutes.**

This matches the **Our Classroom Flow** poster:

```text
Skill Warm-up → Talk Robin 1 → Entry Check → Core Pattern
→ Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence
```

*We learn. Practice. Rebuild. Share.*

## The Seven Blocks (45 minutes)

| Time | Block | Student role | Teacher role |
|---|---|---|---|
| **0–5 min** | **Skill Warm-up (INPUT)** | Meet today’s idea via **one** short video / passage / task | Assign exact clip or page; stop on time |
| **5–9 min** | **Talk Robin 1** | Pair: what was done / what was confusing | Timer + cold call; board one confusion |
| **9–14 min** | **Entry Check** | Individual basics check before going deeper | Scan answers; no full lecture yet |
| **14–19 min** | **Core Pattern** | Watch/listen to the named pattern | Micro-demo only (≤5 min) |
| **19–30 min** | **Guided Practice** | Practice with support (e.g. GitHub Skills steps) | Coach; do not finish the work for them |
| **30–40 min** | **Independent Rebuild** | Rebuild the pattern with checklist; less help | Circulate; no full solution on board |
| **40–45 min** | **Talk Robin 2 + Evidence** | Summarize + submit proof of learning | Verify evidence; 1–2 oral cold calls if time |

Total: **45 minutes**.

## Tight timing rules

- Warm-up video: **≤4–5 minutes** of watching (pause the clip if needed).
- Talk Robin: keep the 45s / 45s / 30s routine.
- Entry Check: **2–3 items**, not 5+.
- Core Pattern: name the pattern; do not re-teach the whole warm-up.
- Unfinished evidence → short finish-up by teacher deadline (not heavy homework).

## One required practice rule

During Guided Practice, use **one** primary practice (e.g. one GitHub Skills course segment). Do not open a second course in the same 45 minutes.

## Evidence rule

Every class ends with durable evidence (commit, screenshot, organizer, reflection, etc.). Watching alone is not enough.
