# AI Studio E — Generalization, Brittleness, and Limits

**Book spine:** assigned sections on generalization, robustness, common sense, or limits of current AI.

## Activity
Teams receive a system that works on ordinary examples but fails under changed conditions. They create a test matrix varying context, input quality, edge cases, and distribution.

## Discussion
Why is a benchmark or successful demo not the same as proving a system will work reliably for every user and context?

## Product Connection
Write acceptance criteria for an AI feature that include failure handling, not only the happy path.

## Evidence
Commit the test matrix and a statement explaining the difference between capability and reliability.
