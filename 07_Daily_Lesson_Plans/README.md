# Daily Lesson Plans

**Course:** Full-Stack Web and AI Application Development

Ready-to-teach **session-by-session** lesson plans following the classroom poster model:

```text
Skill Warm-up → Entry Check → Talk Robin 1 → Teacher Pattern → Guided Practice
→ Independent Rebuild → Talk Robin 2 → Exit Evidence
```

**80-minute default timing:** 0–20 / 20–30 / 30–34 / 34–45 / 45–60 / 60–72 / 72–76 / 76–80

**Course posters:** [05_Public_Documents/posters/](../05_Public_Documents/posters/README.md) — classroom flow, mastery level, CS competition pathways.

## Course Principles (All Lessons)

- Not lecture-only; watching ≠ mastery; copying ≠ mastery
- Rebuild, debug, explain, submit evidence
- AI supports learning — does not replace thinking
- Oral explanation may be required
- Most learning in class; light homework if evidence finished in class

See `shared/classroom-learning-workflow.md` and `02_Assessment/Student_Learning_Expectations.md`.
