# Project Selection Guide

**Teacher-only — private master curriculum**

Designed by Morgan Wang

---

## How to Choose Projects

1. **Align to unit objectives** — see `03_Course_Units/Unit_XX_*/learning_objectives.md`
2. **Match student readiness** — use mastery checks from class missions
3. **Limit cognitive load** — one new concept per mission when possible
4. **Require evidence** — code + README + reflection for every project
