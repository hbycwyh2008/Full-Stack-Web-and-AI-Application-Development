# Lesson 17 — Grid and Responsive Design

## Mission
Build layouts that preserve information hierarchy across screen sizes.

## Core Artifact
A responsive multi-column section using CSS Grid and media/container logic as appropriate.

## Launch Challenge — 0–10
Students compare desktop and mobile versions of a design and mark **what changed position, what changed size, what disappeared, and what must never disappear**.

## Evidence / Resource Scan — 10–25
Inspect examples of Grid tracks, `minmax`, fractional units, and responsive breakpoints. Focus on layout intent rather than memorizing properties.

## Team Sensemaking — 25–40
Teams decide where Grid is better than Flexbox and justify breakpoint behavior from user needs/content, not device brand names.

## Studio Build — 40–65
Implement a responsive section and test at multiple widths. Avoid creating a separate fixed layout for every screen size.

## Critique / Test — 65–80
Peer tests extreme widths, long text, zoom, and keyboard navigation. Record failures as GitHub issues.

## Ship Evidence — 80–90
Fix the highest-impact issue and commit. Leave remaining valid issues open for the sprint.

## Success Evidence
The layout responds to available space while preserving content and task priority.
