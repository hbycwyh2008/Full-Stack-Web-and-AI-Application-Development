## Do Not Skip

```text
Issue
→ branch
→ edit
→ add
→ commit
→ push
→ Pull Request
→ review
→ merge
→ switch main
→ pull
→ deploy
```

## Rule

Collaborators stop after submitting a Pull Request and responding to review feedback. The Owner / Maintainer controls integration into `main`.
