# Optional AI Extension

Use this only when the team's user research and AI literacy analysis justify an AI feature.

Before adding AI, answer:

1. What user need cannot be solved adequately with a simpler deterministic interaction?
2. What inputs/data does the AI feature require?
3. What evidence would show the feature is useful?
4. What errors can it make?
5. How will the interface communicate uncertainty and allow recovery?
6. What privacy, bias, fairness, or access concerns exist?
7. What happens when the model/API is unavailable?
8. How will the feature be tested with users rather than demonstrated only on hand-picked examples?

AI implementation is enrichment. It must not replace the required HCI, Figma, GitHub, HTML/CSS/JavaScript, testing, and release evidence.
