# Exit Evidence — What Counts as Proof

Before class ends, you submit **visible proof** that you learned today’s pattern. Your mission guide lists **exact** requirements for each lesson.

---

## Acceptable Evidence Types

You may submit (depending on the lesson):

| Evidence | Example |
|---|---|
| **GitHub repository link** | `https://github.com/yourname/[studentName]-Full-Stack-Web-and-AI-Application` |
| **GitHub commit screenshot** | Commits tab showing meaningful messages |
| **README update** | Screenshot or link showing changed README |
| **Markdown note** | `lesson-03/notes.md`, `learning-log.md` |
| **Notion portfolio update** | Link or screenshot (when your class uses Notion) |
| **Screenshot** | Oh My Git level, terminal, file tree |
| **Short reflection** | One or two sentences in submission form |
| **Oral explanation** | You answer when the teacher calls on you |
| **Learning log** | Entry in `learning-log.md` |

**GitHub commits** are the main evidence in `01-github-notion`.

---

## What Does NOT Count

- “I watched the video” with no repo change
- Empty files committed for credit
- Commit messages like `update`, `final`, `done` with no real work
- Copied text you cannot explain
- AI-generated answers you did not revise or understand

---

## If You Run Out of Time

Tell your teacher before leaving. You may have a **finish-up deadline** — that is unfinished **class** work, not heavy regular homework.
