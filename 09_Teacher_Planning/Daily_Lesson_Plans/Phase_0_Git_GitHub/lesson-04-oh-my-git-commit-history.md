# Lesson 4: Oh My Git! for Commit and History

**Phase:** 0 — Git & GitHub  
**Duration:** 45 minutes  
**Flow:** [classroom-flow-45-min.md](../shared/classroom-flow-45-min.md)  
**Student repo:** `cs-learning-log`

---

## Lesson Goal

Students use **Oh My Git!** as a **supporting activity** to understand commits and history, then connect the game timeline to **real GitHub commit history** in `cs-learning-log`.

**Do not** require branches, merge, or index sections in this beginner unit.

---

## Resources

| Resource | URL | Use in class |
|---|---|---|
| Oh My Git! | https://ohmygit.org/ | Selected intro levels only |

### Required Oh My Git levels only

1. **Living dangerously**
2. **Making backups**
3. **The command line**
4. **Your first commit**

**Do not assign:** branches, merge, index deep sections.

---

## Core Vocabulary

| Term | Definition |
|---|---|
| **Snapshot** | Saved state of files (like a commit) |
| **Timeline** | Sequence of snapshots |
| **Backup** | Saved state you can return to |
| **Metaphor** | Game idea that maps to real Git behavior |

## 45-Minute Lesson Flow

| Time | Block |
|---|---|
| 0–5 min | Skill Warm-up (INPUT) |
| 5–9 min | Talk Robin 1 |
| 9–14 min | Entry Check |
| 14–19 min | Core Pattern |
| 19–30 min | Guided Practice |
| 30–40 min | Independent Rebuild |
| 40–45 min | Talk Robin 2 + Exit Evidence |

---

### 0–5 min: Skill Warm-up (INPUT)

Play or demo **Living dangerously** + **Making backups** (stop at 20 min even if incomplete).

**Note while playing:**

- What happens without backup?
- How is “backup” like a **commit**?

---

### 5–9 min: Talk Robin 1

- **A:** “A commit is like ___ in the game because…”
- **B:** “GitHub history shows evidence because…”
- **Shared:** Which level we play next in Guided Practice.

---

### 9–14 min: Entry Check

1. In Oh My Git, what problem does “making backups” solve?
2. How is the game timeline like GitHub’s **Commits** tab?
3. How many commits are in your real repo right now?
4. Why is the game **not** enough evidence by itself?
5. What will you add to `lesson-04/notes.md` today?

---

### 14–19 min: Core Pattern

**Map game → GitHub:**

| Game | GitHub |
|---|---|
| Backup / snapshot | Commit |
| Timeline | Commit history |
| Label on backup | Commit message |
| View old state | View past commit |

**Branches:** mention only — “we learn later.”

**GitHub work today:**

1. Screenshot Oh My Git progress
2. Create `lesson-04/notes.md`:
   - Levels played
   - Connection to Commits tab
   - One new insight about history as evidence
3. Commit: `Add lesson-04 notes connecting Oh My Git to commit history`

---

### 19–30 min: Guided Practice

- **45–52 min:** **The command line** + **Your first commit** (class-paced)
- **52–60 min:** Draft `lesson-04/notes.md`; teacher shows Commits tab beside game screenshot

Balance screen time — GitHub evidence is mandatory exit.

---

### 30–40 min: Independent Rebuild

**Checklist:**

- [ ] At least **3 of 4** intro levels completed (or teacher alternative)
- [ ] Oh My Git screenshot saved/submitted
- [ ] `lesson-04/notes.md` — 3+ sentences connecting game to GitHub
- [ ] Meaningful commit on `cs-learning-log`
- [ ] Can explain connection without reading notes verbatim

---

### 40–45 min: Talk Robin 2 + Exit Evidence

- **A:** “Game timeline → commit history means…”
- **B:** “My GitHub evidence today is…”
- **Shared:** Exit Evidence.

## Common Mistakes

- Playing branch levels off-unit
- Screenshot only — no `lesson-04/notes.md`
- Notes: “fun game” with no GitHub link
- Commit message: `lesson 4`
