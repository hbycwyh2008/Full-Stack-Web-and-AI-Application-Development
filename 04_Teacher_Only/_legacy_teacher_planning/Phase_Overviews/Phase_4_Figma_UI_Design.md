# Phase 4: Figma UI Design

**Your goal:** Design the **AI School Assistant** interface in Figma **before** you code it in TypeScript and Next.js.

---

## What You Will Learn

- Wireframes, frames, components, navigation
- Design-first workflow: plan UI → then build (Phases 5–6)
- How to show **answer + source** on the result screen (RAG UX)

---

## Why This Matters

Coding without a plan wastes time. Your Figma mockup becomes the blueprint for Next.js components and proves you thought about user flow and responsible AI display (sources visible).

---

- [ ] Phases 0–3 evidence on GitHub

## In-Class Learning Flow

### 1. Skill Warm-up
Sketch user flow on paper: question → loading → answer → **source**. Take photo or paste into notes.

### 2. Talk Robin Round 1
- **You:** “The main user action on my app is…”
- **Partner:** “Where the source will appear is…”

### 3. Entry Check
1. Name four screens you will design.
2. Why design before code?

### 4. Core Pattern
```text
user flow → wireframe → components → polish → figma link → commit design/figma-link.md
```

### 5. Guided Practice
Build in Figma: Home, question input, result with source, navigation.

### 6. Independent Rebuild
- [ ] 3–4 screens with consistent components
- [ ] Source visible on result screen
- [ ] `figma-design/README.md` + `figma-link.md`
- [ ] Screenshot in repo

### 7. Talk Robin Round 2 + Evidence
Submit Figma link + GitHub commit.
