# Mastery Levels — What “Learning” Means in This Course

Your grade and growth depend on **what you can do**, not only what you watched.

![Mastery Level — Not just working code. Real understanding.](../../08_Public_Documents/posters/mastery-level.png)

*Course poster: [mastery-level.png](../../08_Public_Documents/posters/mastery-level.png)*

> **Running code once is not mastery.** You must explain, rebuild, debug, modify, and submit evidence. See Levels 0–5 below.

## Grade-Band Mastery Targets

Middle School and High School students use the **same mastery scale**, but the expected target is different.

### Middle School — Guided Full-Stack Development

- Most topics: **Level 2–3**
- Selected core skills: **Level 3 consistently**
- Level 4–5: encouraged for advanced students, but not required across the entire course

**Core expectation:** Build · Modify · Explain

### High School — Independent Full-Stack AI Development

- Most core topics: **minimum Level 3**
- Major programming and application-development skills: **target Level 4**
- Capstone and selected core skills: **target Level 4–5**

**Core expectation:** Rebuild · Debug · Integrate · Transfer

See [Grade-Band Expectations](../../00_Course_Overview/Grade_Band_Expectations.md) for the complete track requirements.

---

## Level 0: Exposure

You have **seen** the concept through a short video, reading, example, or teacher demonstration.

**Example:** You watched a GitHub intro clip but cannot create a repo alone.

**Not enough** by itself for course credit.

---

## Level 1: Copy and Run

You can **follow instructions**, copy the example, and make it work.

**Example:** You repeat the teacher’s steps and your README appears.

---

## Level 2: Explain While Looking

You can **look** at the code, command, or project and explain what the important parts do.

**Example:** You open your Commits tab and explain what your last commit changed.

---

## Level 3: Rebuild with a Checklist

You can **recreate the same pattern** using a short checklist — **without copying the full solution**.

**Example:** Checklist says “folder → notes.md → commit” — you do it without paste.

**Target minimum** for most lessons.

---

## Level 4: Rebuild Without Notes

You can recreate the pattern from a **blank file, blank page, or terminal** without notes, tutorials, AI answers, or solution code.

**Example:** Teacher asks for a new lesson folder — you do it cold.

---

## Level 5: Modify, Debug, and Transfer

You can use the pattern in a **new situation**, **modify** it, and **debug** common errors.

**Example:** You fix a bad commit message, help a peer find a missing push, adapt the pattern to a new file.

---

## Principles — Read These Carefully

- **Watching is not mastery.**
- **Copying is not mastery.**
- **Running code once is not mastery.**
- **Understanding** code is not the same as being able to **rebuild** it.
- **Debugging** is part of learning, not failure.
- **AI tools** can support learning, but they **cannot replace thinking**.

You may be asked to explain your work **orally**. You must submit **visible evidence** (see `exit-evidence-checklist.md`).
