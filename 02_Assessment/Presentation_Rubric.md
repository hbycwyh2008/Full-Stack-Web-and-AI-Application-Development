# Presentation Rubric

Use this rubric to assess the final demo and presentation.

| Criterion | What to Look For | Score (1–5) |
|---|---|:---:|
| Clarity of demo | The demo runs smoothly and the purpose is clear. | |
| Explanation of architecture | Student explains frontend, backend, database, and AI parts. | |
| Explanation of data flow | Student traces a request from user input to response. | |
| Explanation of AI usage | Student clearly states what AI did and what they did. | |
| Ability to answer technical questions | Student responds accurately to follow-up questions. | |

---

## Scoring Guide

```text
5 — Excellent: clear, accurate, confident
4 — Strong: mostly clear with minor gaps
3 — Adequate: understands the basics
2 — Developing: significant gaps
1 — Needs work: cannot explain
```

## Notes for the Teacher

- Ask at least one follow-up question per category.
- Reward honest "I don't fully understand this part yet" answers over vague confidence.
