# Phase 0: Git & GitHub

## Phase Goal
Learn Git and GitHub as the first course phase — your long-term project archive and portfolio evidence before AI literacy and coding.

## Key Concepts
- What Git and GitHub are; repository, commit, branch, pull request, merge.
- Clone, push, pull, and `.gitignore`.
- Markdown for README files.
- GitHub as **evidence of real learning**.

## Required Student Output
- A public repository: `student-portfolio`
- Folder structure:

```text
student-portfolio/
├── README.md
├── projects/
├── ai-literacy/
├── ai-math-bridge/
├── certificates/
└── reflections/
```

- At least three meaningful commits.
- Branch and pull request practice (GitHub Skills or class equivalent).

---

## Suggested Lesson Count
3 lessons.

## Lesson Sequence

### Lesson 1: Markdown and Your First Repo
- **Goal:** Write Markdown and create the `student-portfolio` repository.
- **Warm-up:** Plain text vs. formatted Markdown — which is easier to read?
- **Mini Lesson:** Markdown basics; what a repository is; create repo and first README.
- **Guided Practice:** Create GitHub account (if needed), create `student-portfolio`, add folders and README.
- **Independent Work:** Fill in README: name, grade, course goal, link placeholders.
- **Exit Ticket:** Write a Markdown heading, list, and link from memory.
- **Homework:** **Markdown Crash Course**; start **GitHub Skills: Introduction to GitHub**.

### Lesson 2: Commits and Git Workflow
- **Goal:** Understand commits, push, and clear commit messages.
- **Warm-up:** "What could go wrong if you never saved versions of your work?"
- **Mini Lesson:** Commit, push, pull; personal access token sign-in if needed.
- **Guided Practice:** Three commits with clear messages; add `projects/` and `reflections/` folders.
- **Independent Work:** Add `GitHub_Profile_README_Template.md` content to profile repo (optional stretch).
- **Exit Ticket:** Explain what a commit is in one sentence.
- **Homework:** Finish GitHub Skills through "Commit changes."

### Lesson 3: Branch, Pull Request, and Practice
- **Goal:** Use branch and merge workflow; optional interactive Git practice.
- **Warm-up:** "Why might two people edit the same project at once?"
- **Mini Lesson:** Branch, checkout/switch, merge, pull request. Demo: branch → edit README → PR → merge.
- **Guided Practice:** Complete GitHub Skills (branch + PR + merge) or class equivalent on a practice branch.
- **Independent Work:** **Learn Git Branching** — early levels (commit, branch, merge).
- **Exit Ticket:** What is a pull request?
- **Homework:** Confirm repo is public and organized; prepare for Phase 1 (`ai-literacy/` folder).

## Submission Requirements
- [ ] Public `student-portfolio` repo with required folders.
- [ ] Clear README.md.
- [ ] At least three meaningful commits.
- [ ] Branch/PR practice completed (GitHub Skills or teacher sign-off).

## Common Student Problems
- Authentication fails → prepare a personal access token guide.
- Vague commit messages → require messages that say what changed.
- Forgetting to push → "saved locally" is not "on GitHub."
- Skipping branch/PR → treat as required workflow practice.

## Teacher Notes
> Git 是第一阶段，为后续 AI 素养笔记和项目代码打基础。Git comes first so students have a home for `ai-literacy/` work in Phase 1. Budget extra time for authentication.

## AI Lens Reflection
Ask students: *"When you later use AI to help write code, how will commits and README show what you understood versus what AI generated?"* Note the answer in `reflections/`.
