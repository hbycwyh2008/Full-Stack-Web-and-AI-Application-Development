# HTML & CSS Profile Page

## Goal

Build a simple personal profile page using HTML and CSS.

## What You Will Build

A single profile page with:

- semantic HTML structure (`header`, `main`, `section`, `footer`)
- a short about section and skills list
- CSS in a separate file (`style.css`)
- your own colors and spacing (not only browser defaults)

## Starter Files

Open the `starter_files/` folder:

- `README.md` — how to use the starter files
- `index.html` — HTML scaffold (incomplete — you must edit)
- `style.css` — minimal CSS starter (you must add your own rules)

## Required Tasks

1. Copy `index.html` and `style.css` into a folder in your portfolio repo (for example `projects/profile-page/`).
2. Replace placeholder text with your own content.
3. Add CSS rules for layout, colors, and typography in `style.css`.
4. Use **semantic HTML** — not only `<div>` for everything.
5. Open the page in a browser and fix any display issues.
6. Commit with meaningful messages and push to GitHub.

## Evidence to Submit

- [ ] `index.html` in your GitHub repo
- [ ] `style.css` in your GitHub repo
- [ ] Screenshot of the page in a browser
- [ ] GitHub commit history showing your work
- [ ] Completed `reflection.md`

## Reflection Questions

1. Why use semantic HTML tags instead of only `<div>` elements?
2. What CSS change made the biggest visual difference on your page?
3. Did you use AI for help? What did you test or change yourself?

## Extension Challenge

Add a hover effect on links or a simple responsive rule so the page looks better on a phone-width screen.
