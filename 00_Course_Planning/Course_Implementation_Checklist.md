# Course Implementation Checklist

A practical checklist to complete before launching the course. Adapt items to your school context.

---

## Before the Course Starts
- [ ] Read `README.md` and `00_Course_Planning/Course_Overview.md`.
- [ ] Review `00_Course_Planning/Course_Pacing_Guide.md` and choose 16-week or 8-week.
- [ ] Review the full learning flow (Phases 0–11).
- [ ] Read `02_Assessment/AI_Usage_Policy.md` and adapt to school rules.

## Accounts and Tools
- [ ] Notion access for all students.
- [ ] GitHub access for all students.
- [ ] Cursor installed.
- [ ] Python installed.
- [ ] Node.js installed.

## Required Teacher Demo
- [ ] Teacher demo runs locally (`06_Starter_Code/teacher-demo-ai-school-assistant/`).
- [ ] Full RAG app runs locally (`06_Starter_Code/ai-school-assistant/`).
- [ ] ChromaDB running via `docker compose up -d` in `ai-school-assistant/`.
- [ ] Backend health endpoint works (http://localhost:8000).
- [ ] Frontend works (http://localhost:3000).
- [ ] Completed the demo tests in `TESTING.md`.
- [ ] Reviewed `04_Lesson_Materials/Teacher_Demo_Walkthrough.md`.

## Student Templates Ready
- [ ] `01_Student_Templates/Student_Portfolio_Template.md` ready to hand out.
- [ ] `01_Student_Templates/Project_README_Template.md` ready.
- [ ] `01_Student_Templates/GitHub_Profile_README_Template.md` ready.
- [ ] `01_Student_Templates/AI_Math_Bridge_README_Template.md` ready.

## Assessment Ready
- [ ] `02_Assessment/Assessment_Rubric.md` reviewed.
- [ ] `02_Assessment/Presentation_Rubric.md` reviewed.
- [ ] `02_Assessment/AI_Literacy_Checklist.md` reviewed.
- [ ] `02_Assessment/AI_Math_Bridge_Checklist.md` reviewed.
- [ ] Grade weights adjusted to your context.

## Week 1 Preparation
- [ ] Phase 0 lesson plan reviewed (`04_Lesson_Materials/Phase_0_Git_GitHub.md`).
- [ ] Phase 1 Notion plan reviewed (`Phase_1_Notion_Portfolio.md`).
- [ ] Phase 2 AI literacy plan reviewed (`Phase_2_AI_Literacy_Foundation.md`).
- [ ] Phase 3 AI Math Bridge reviewed (`00_AI_Math_Bridge/`, `Phase_3_AI_Math_Bridge_Linear_Algebra.md`).
- [ ] 3Blue1Brown + DeepLearning.AI LA links verified; NumPy/Jupyter available for labs.

## Technical Setup
- [ ] Personal access token guide ready for GitHub authentication.
- [ ] Example CORS config ready for Phase 9.
- [ ] Confirmed `.env` is gitignored in the teacher demo.
- [ ] Confirmed students know not to commit secrets.

## Safety and AI Usage
- [ ] AI Usage Policy shared with students.
- [ ] Responsible AI Checklist explained.
- [ ] School-specific privacy/AI placeholders reviewed and filled in.
- [ ] No real API keys committed anywhere.

## Public Communication
- [ ] `05_Public_Documents/Student_Overview.md` shared with students.
- [ ] `05_Public_Documents/Parent_Overview.md` shared with families.
- [ ] `05_Public_Documents/School_Proposal.md` shared with leadership.

## Ready-to-Launch Sign-Off
- [ ] All accounts and tools confirmed.
- [ ] Teacher demo runs and is understood.
- [ ] Week 1 materials prepared.
- [ ] Assessment and policies ready.
- [ ] No secrets committed.
