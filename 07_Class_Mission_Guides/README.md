# Class Mission Guides

**For students:** Open the mission guide for **today’s class** and follow it step by step.

These guides tell you exactly:

- what you need to do today
- what resources you may use
- what pattern you need to learn and rebuild
- what you need to discuss with your partner
- what evidence you must submit before class ends

---

## This Is Not a Traditional Lesson Plan

**Class Mission Guides** are written **for you** — not for the teacher.

## How Every Class Works (80 Minutes)

See `shared/classroom-flow.md` for the full flow.

```text
Skill Warm-up → Entry Check → Talk Robin 1 → Core Pattern
→ Guided Practice → Independent Rebuild → Talk Robin 2 → Exit Evidence
```

**Important:** The first 20 minutes are **not** passive video time. You complete a small task and produce something.

## Course Principles (Every Mission)

- Watching is not mastery.
- Copying is not mastery.
- Running something once is not mastery.
- You must **rebuild**, **debug**, **explain**, and **submit evidence**.
- AI can help you understand — it cannot replace your thinking.
- You may be asked to explain your work **orally**.
