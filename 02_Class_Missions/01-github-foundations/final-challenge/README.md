This is the final Git/GitHub mastery exercise for the GitHub Foundations unit. It is designed to feel like a GitHub Skills activity: students progress through missions, create real GitHub artifacts, and receive checkpoint feedback.

## Recommended Use

1. Assign teams of three.
2. Give each student the shared mission plus the role card for their assigned role.
3. The Owner creates `team-web-launch` and, if desired, copies the starter pack into the new repository.
4. Use the mission gates in the Teacher Guide to control progression.
5. If the starter workflow is installed, use the automatically updated **🚀 GitHub Team Launch Progress** Issue as the team's interactive checkpoint page.
6. Grade GitHub artifacts rather than screenshots whenever possible.

## Mastery Flow

```text
Issue / Project
→ clone
→ feature branch
→ edit
→ add
→ commit
→ push
→ Pull Request
→ Owner review
→ merge
→ switch main
→ pull
→ GitHub Pages
```

The challenge deliberately reduces scaffolding as students progress. The final evidence is the repository history plus the deployed GitHub Pages site.
