# 00 — Computer Science Orientation + Software Lifecycle

The course begins before GitHub or coding with a more basic question: **What is computer science?**

Students should leave this unit understanding that computer science studies computation and information across areas such as algorithms, abstraction, data, systems/networks, security, HCI, software engineering, AI, theory, and societal impacts. Programming is an important practice inside CS, not the complete discipline.
