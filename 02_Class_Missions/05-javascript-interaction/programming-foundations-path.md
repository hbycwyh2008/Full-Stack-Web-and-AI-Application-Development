# Programming Foundations and Figma-to-Code Path

**Full Stack course stage:** after AI literacy and Figma design, students learn the foundations needed to turn their existing design into a working browser page.

## Required Coursera sequence

| Step | Course | Focus | Student evidence |
|---|---|---|---|
| 1 | [Scrimba: Learn HTML and CSS](https://www.coursera.org/learn/learn-html-and-css) | HTML structure, CSS styling, layout, and responsive pages | Build and explain a small static page |
| 2 | [Scrimba: Learn JavaScript](https://www.coursera.org/learn/learn-javascript) | Variables, data types, functions, conditions, loops, arrays, DOM, events, and basic interaction | Complete small coding challenges; explain and independently change one interaction |
| 3 | [Build Websites with Figma, HTML, and CSS (From Figma to Code)](https://www.coursera.org/learn/from-figma-to-code) | Translate Figma mockups into responsive web interfaces and compare independent work with guided examples | Implement a selected screen from the student's own tested Figma prototype |

The Figma-to-code course is the application project. Use it after students have the basic HTML/CSS and JavaScript skills to work through the mockups. The course page lists it as intermediate and describes five design-to-web projects; teachers can assign selected modules and projects instead of requiring every item.

## Course sequence in class

1. Review the student's tested Figma screen and identify its sections and interactions.
2. Learn the needed HTML/CSS through Scrimba's beginner course and implement the page structure and styling.
3. Learn the JavaScript fundamentals through Scrimba and practice one interaction at a time.
4. Return to the Coursera Figma-to-code projects and apply the skills to a selected screen from the student's own design.
5. Test on different viewport sizes, compare expected and actual behavior, make one evidence-based revision, and explain the code.

Use the existing lessons as classroom support:

- Lessons 12–15: semantic HTML, CSS, responsive layout, and implementation from Figma.
- Lessons 16–20: values, state, functions, control flow, arrays/objects, DOM, events, forms, and debugging.

Keep the course scope on browser-based HTML, CSS, JavaScript, and interaction. Advanced frameworks and backend development are outside this programming stage.
