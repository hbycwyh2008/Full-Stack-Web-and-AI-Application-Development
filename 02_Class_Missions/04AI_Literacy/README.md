## 90-Minute Flow (Every Class)

```text
0–15   Individual Learning (assigned AI for Everyone week / videos)
15–27  Talk Robin / Group Discussion
27–37  Group Answer
37–45  Entry Points Check
45–70  Mission Task (write in ai-literacy/, commit)
70–80  Independent Rebuild / Exit Check (explain in own words)
80–90  Submission of Evidence
```
