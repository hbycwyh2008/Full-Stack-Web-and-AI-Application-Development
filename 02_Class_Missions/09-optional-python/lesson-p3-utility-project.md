# Optional Python P3 — Small Utility Project

**Length:** 90 minutes  
**Mission:** Apply transferred Python skills to a small useful utility without expanding Python into a new major course strand.  
**One Required Resource / Evidence Source:** approved utility brief + prior Python notes/code  
**Durable Evidence:** working utility + README + test evidence

## 0–10 min — Entry Point Check

Individually choose one small utility problem that can be completed with basic Python, such as file renaming, text statistics, simple data cleanup, quiz scoring, or another teacher-approved task. Define input, output, and success criteria.

## 10–25 min — Individual Learning

Review only the prior Python examples needed for the chosen task. Identify reusable patterns for input, variables/data structures, functions, control flow, file/data handling, and testing.

## 25–40 min — Talk Round 1

Pairs review each other's plan for scope and testability. Remove one unnecessary feature and identify one edge case before coding.

## 40–55 min — Entry Points Check / Teacher Diagnosis

Groups present a short algorithm/data-flow plan and one likely blocker. Teacher gives only targeted clarification for common barriers; this optional unit should not become a new full Python sequence.

## 55–75 min — Guided Practice / Mission Task

Build the utility with:

- clear input/output;
- at least one function;
- appropriate data structure;
- selection and/or iteration;
- basic error/edge-case handling;
- several tests;
- concise README instructions.

## 75–85 min — Exit Check

Individually explain one part you could transfer back to JavaScript or another language and one part that is specifically Python syntax/library behavior.

## 85–90 min — Submission

Submit code, README, test evidence, and individual exit response.

## Success Evidence

Students can independently apply basic Python to a bounded utility and recognize language-specific syntax versus transferable computational ideas.
