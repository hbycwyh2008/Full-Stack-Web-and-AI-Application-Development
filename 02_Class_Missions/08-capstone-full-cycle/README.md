# 08 — Capstone: Full Software-Development Cycle

The capstone is not simply `build a website`. Students repeat the complete process with reduced scaffolding and preserve evidence of decisions.

## Required Evidence Chain

```text
research
→ synthesis/problem
→ requirements/success criteria
→ Figma design/prototype
→ GitHub backlog/branches/PRs
→ HTML/CSS/JavaScript implementation
→ usability + technical testing
→ revision
→ release
→ retrospective
```

AI is optional. The capstone is successful when the product and evidence are strong, not when the technology list is long.
