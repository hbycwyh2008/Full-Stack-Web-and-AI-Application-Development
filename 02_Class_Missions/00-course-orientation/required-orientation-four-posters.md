# Required Orientation — Learn the Course Through the Four Posters

**This session happens before Lesson 00, before “What Is Computer Science?”, and before the AP CSP CED discovery activity.**

**Length:** 90 minutes  
**Mission:** Understand how learning, mastery, AI use, and optional competition pathways work in this course.  
**One Required Resource:** [Course Posters](../../08_Public_Documents/posters/README.md)  
**Durable Evidence:** individual poster evidence + group claim board + exit transfer

The four posters are:

1. **Our Classroom Flow**
2. **Mastery Level**
3. **AI Use Policy**
4. **CS Competition Pathways**

This is not a syllabus lecture. Students learn the course culture by using the same classroom flow they will experience later.

---

## 0–10 min — Entry Point Check

**Work individually. Do not discuss yet.**

For each statement, mark **Agree / Disagree / Unsure** and write a five- to ten-word reason.

| Statement | Decision | Short reason |
|---|---|---|
| If my code works once, I have mastered it. |  |  |
| Asking AI to explain an error can support learning. |  |  |
| Rebuilding something without the full example is stronger evidence than copying it. |  |  |
| Competitions are required to succeed in this course. |  |  |
| Discussion should help me revise my thinking, not just give the teacher an answer. |  |  |

Circle the statement you are least certain about.

---

## 10–25 min — Individual Learning: Four-Poster Gallery Scan

Open only the [Course Posters](../../08_Public_Documents/posters/README.md).

For each poster, record **one piece of evidence** and **one implication for your behavior**.

| Poster | Evidence I noticed | What this means I should do |
|---|---|---|
| Our Classroom Flow |  |  |
| Mastery Level |  |  |
| AI Use Policy |  |  |
| CS Competition Pathways |  |  |

Then draw one connection between two posters and complete:

> These posters connect because ____________________________________________.

Do not copy another student's wording.

---

## 25–40 min — Talk Round 1

Work in pairs.

### Round A — Evidence Share

Each student has up to 60 seconds to share:

- one poster claim;
- the evidence that supports it;
- one behavior it should change.

The listener records one idea they did not originally notice. Switch roles.

### Round B — Agreement + Tension

Together record:

- **One point we agree on:** ______________________________________
- **One point we interpret differently / are unsure about:** __________________

### Round C — Connect the Posters

Choose **two posters** and write a two-sentence explanation of how they work together.

Example structure:

> The __________ poster tells us __________. The __________ poster matters because __________.

Do not prepare an answer for the teacher. Prepare a claim you can defend with poster evidence.

---

## 40–55 min — Entry Points Check / Teacher Diagnosis

Join a group of 3–4 and create a **Four-Poster Claim Board**.

### Box 1 — Classroom Flow

Place these actions in the order that best represents the course:

`individual attempt` · `learn from evidence/resource` · `discuss` · `diagnose` · `practice/build` · `individual transfer check` · `submit evidence`

### Box 2 — Mastery

Sort each example into **Weak Evidence / Stronger Evidence**:

- watched a tutorial;
- copied working code;
- can explain the logic;
- can rebuild the pattern;
- can debug a changed version;
- can apply the idea in a new situation.

### Box 3 — AI Use

Sort each scenario into **Supports Learning / Replaces Thinking / Needs More Context**:

- AI explains an error, then the student fixes and explains it;
- AI writes the whole task and the student submits it unchanged;
- AI proposes two approaches and the student tests both;
- AI produces code the student cannot explain;
- the student documents how AI was used.

### Box 4 — Competition Pathways

Write:

- one reason a student might choose a competition pathway;
- one reason competition is **not** the definition of success in this course.

Finally add exactly **one unresolved point** your group still has.

### Teacher diagnosis

The teacher scans group boards. Only shared misconceptions or unresolved points receive a short clarification. The class does not become a fifteen-minute teacher Q&A.

---

## 55–75 min — Guided Practice / Mission Task: Course Culture Scenario Lab

Each group receives four scenarios. For each scenario:

1. identify the poster(s) that apply;
2. decide what the student should do next;
3. cite the specific poster idea supporting the decision.

### Scenario A — It Works

A student follows a coding example exactly and the page works.

What should happen next to show mastery?

### Scenario B — AI Debugging

A student asks AI why an error occurs, tests the explanation, fixes the code, and can explain the change.

What evidence should the student preserve?

### Scenario C — AI Replacement

A student pastes an AI-generated solution into an assignment and cannot explain the functions.

What course expectation has not been met?

### Scenario D — Competition Pressure

A student thinks they are “behind” because they do not want to enter a CS competition.

What does the competition poster actually say about course success?

### Mini simulation of the classroom flow

As a group, label which parts of **today's class** correspond to the seven blocks on the Classroom Flow poster. Students should recognize that they have already experienced the flow rather than merely reading about it.

---

## 75–85 min — Exit Check

Return to the five Entry Point statements.

Individually:

1. change any decision you would now answer differently;
2. choose one changed or strengthened idea;
3. explain the evidence that changed/strengthened it.

Then complete:

> **In this course, successful learning is not just ____________________. It requires ____________________.**

> **The poster I will probably need to remember most often is ____________________ because ____________________.**

---

## 85–90 min — Submission

Submit:

1. Entry Point Check;
2. four-poster evidence table;
3. partner agreement/tension notes;
4. group Four-Poster Claim Board;
5. individual Exit Check.

## Success Evidence

Students are ready for Lesson 00 when they can:

- describe the seven-block classroom flow in their own words;
- distinguish completion from mastery;
- distinguish AI support from AI replacement;
- explain that competition pathways are optional enrichment;
- use poster evidence to justify a decision about classroom behavior.
