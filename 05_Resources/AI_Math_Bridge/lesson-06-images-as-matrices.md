# Lesson 6: Images as Matrices

## Goal

Understand that **images are numerical data** — pixels are numbers.

## Key Ideas

- Grayscale image → 2D matrix of pixel values.
- RGB image → 3D array (channels).
- Basic image processing uses matrix operations.

## Activities

1. Inspect a small pixel grid or image array on screen.
2. Write computer vision connection in `ai-math-bridge/README.md`.
3. Plan the image matrix mini project (Lesson 10).

## Student Output

- README update: "Why images are matrices"
- Prepare for `image-as-matrix-lab.ipynb`

## Exit Ticket

Grayscale vs RGB — how is the data shaped differently?
