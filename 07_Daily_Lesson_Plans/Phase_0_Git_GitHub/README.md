## Lessons

| # | Title | Mastery target (typical) |
|---|---|---|
| 1 | Course Workflow and First GitHub Repository | Level 1–2 |
| 2 | README and Commit History | Level 2–3 |
| 3 | File Organization and Learning Log | Level 3 |
| 4 | Oh My Git! for Commit and History | Level 2–3 |
| 5 | Local Git with VS Code and Terminal | Level 3 |
| 6 | GitHub Mastery Check | Level 3+ (4–5 strong) |

---

## Unit Goal

Students use GitHub as **learning evidence**: repository, README, Markdown files, meaningful commits, commit history, basic local workflow (if ready), oral explanation, and Exit Evidence every lesson.

**Not in this unit:** branches, pull requests, merge conflicts, rebase, advanced Git internals.
