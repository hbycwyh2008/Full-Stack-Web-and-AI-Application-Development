# How to Use Daily Lesson Plans

## What This Folder Is

`09_Teacher_Planning/Daily_Lesson_Plans/` contains **ready-to-teach, session-by-session** lesson plans. It does **not** replace:

- `09_Teacher_Planning/Phase_Overviews/` — phase overviews and pacing
- `03_Templates/` — student portfolio templates
- `04_Assessment/` — rubrics and sign-off
- `05_Resources/Git_GitHub_Unit/` — extended handouts and rubrics (optional supplement)

**Use daily plans when you need:** exact 80-minute block timing, Talk Robin prompts, Exit Evidence lists, and Independent Rebuild checklists.

---

## Before Each Lesson

1. Read the daily plan for that session.
2. Print or share `shared/mastery-levels.md` and `shared/talk-robin-rules.md` (Lesson 1).
3. Open projector demo account / sample repo.
4. Check devices and GitHub authentication; prepare Git or GitHub Desktop
   before Lesson 5, Pages before Lesson 11, and VS Code before Lesson 14.
5. Prepare Exit Evidence submission form (LMS, QR, or shared doc).

---

## During Class

Follow the eight blocks in order. **Do not skip** Independent Rebuild or Exit Evidence to “finish the video.”

| If running short | Cut this | Do not cut |
|---|---|---|
| Time pressure | Optional extension, second video clip | Independent Rebuild, Exit Evidence |
| Time pressure | Homework preview | Talk Robin Round 2 (can shorten cold call to 1 min) |

Use a visible timer for Talk Robin (45s / 45s / 30s).

---

## After Class

- Collect Exit Evidence same day when possible.
- Note unfinished practice so it can continue next class.
- Only the day’s `learning-log.md` Exit Ticket may be finished at home.
- Log common mistakes for next Entry Check.

---

## Phase 0 Student Repo

Daily plans use **`YourName-Full-Stack-Web-and-AI-Application-Development`** for teaching clarity. You may later align with **`student-portfolio`** per `Student_GitHub_Repository_Guide.md` — tell students explicitly.

---

## Adding Future Phases

Copy `shared/lesson-plan-template.md` into `Phase_X_Name/lesson-NN-....md`. Keep the eight-block structure.
