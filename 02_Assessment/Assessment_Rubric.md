# Assessment Rubric

Use this rubric to grade student projects. Adjust weights to match your school context if needed.

## Weighting

| Category | Weight |
|---|---:|
| Portfolio organization | 15% |
| GitHub + README quality | 15% |
| Frontend functionality | 20% |
| Backend API functionality | 20% |
| Full-stack integration | 15% |
| AI-assisted development reflection | 10% |
| Presentation / demo | 5% |

---

## Category Descriptions

### Portfolio organization (15%)
Clear structure, complete sections, professional presentation in Notion.

### GitHub + README quality (15%)
Repository is organized; README follows the template; documentation is clear and complete.

### Frontend functionality (20%)
The frontend runs, is usable, and implements the required features.

### Backend API functionality (20%)
The backend exposes working endpoints with correct responses and basic error handling.

### Full-stack integration (15%)
Frontend and backend communicate correctly; data flows end to end.

### AI-assisted development reflection (10%)
Honest, specific reflection on AI usage; clear distinction between AI-generated and student work.

### Presentation / demo (5%)
Clear demo; student can explain architecture, data flow, and decisions.

---

## Key Assessment Questions

```text
Can the student explain the architecture?
Can the student explain the data flow?
Can the student debug basic issues?
Can the student document the project clearly?
Can the student distinguish AI-generated code from their own decisions?
```
