# Lesson 15 — CSS Typography, Color, and Spacing

## Mission
Convert visual design decisions into a small, consistent CSS system.

## Core Artifact
`styles.css` with reusable foundational styles.

## Launch Challenge — 0–10
Compare two pages with identical content but inconsistent versus systematic spacing/type. Students mark which differences make hierarchy easier to understand.

## Evidence / Resource Scan — 10–25
Extract from Figma: type scale, color roles, spacing patterns, border/radius rules, and component states. Record design values instead of eyeballing every element independently.

## Team Sensemaking — 25–40
Teams decide which values deserve variables/custom properties and which are one-off exceptions. Challenge unnecessary exceptions.

## Studio Build — 40–65
Implement base styles and CSS custom properties for the project's visual system. Apply readable line length, hierarchy, contrast, focus states, and consistent spacing.

## Critique / Test — 65–80
Peer compares implementation with Figma and accessibility criteria. Report the three highest-impact mismatches, not every pixel difference.

## Ship Evidence — 80–90
Revise and commit with a short note listing one visual and one accessibility improvement.

## Success Evidence
Students can explain how a visual system reduces inconsistency and makes later changes easier.
