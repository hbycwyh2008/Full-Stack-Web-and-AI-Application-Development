# Teacher Implementation Model

**Computer Science and AI Pathway**  
Designed by Morgan Wang

---

## Overview

Teachers implement the pathway using a **three-layer architecture**:

| Layer | Location | Audience |
|---|---|---|
| **Private master curriculum** | This repository | Teachers, curriculum designers |
| **Student Hub export** | `01_Student_Hub_Export/` → separate repo | Students |
| **GitHub Classroom templates** | `02_GitHub_Classroom_Templates/` → org templates | Students per assignment |

---

## Recommended Class Structure (90 minutes)

```text
1. Learn      — short intro, demo, or mission briefing (15–20 min)
2. Practice   — students work on mission with starter code (40–45 min)
3. Rebuild    — independent rebuild or memory-only practice (15–20 min)
4. Share      — exit evidence, oral check, or peer review (10–15 min)
```

---

## Teacher Responsibilities

1. **Prepare** using `04_Teacher_Only/` (lesson plans, scripts, phase overviews).
2. **Assign** work via GitHub Classroom using sanitized templates — not the master repo.
3. **Assess** using rubrics in `05_Assessment_and_Rubrics/`.
4. **Verify mastery** through explain · rebuild · debug · modify · apply.
5. **Export** only student-safe materials to the Student Hub.

---

## What Teachers Should Not Share With Students

- Full master repository access
- Answer keys and detailed grading notes
- Complete project bank
- Full Cursor / teacher prompt library
- Internal planning notes
