# Lesson 09 — Create 3 Prototypes (Low-Fi)

**Length:** 45 minutes  
**Loop step:** Create 3 Prototypes  
**Mission:** Build three different low-fidelity prototypes for the same user goal, then pick one direction using evidence — not taste alone.  
**One Required Resource / Evidence Source:** Lesson 08 brainstorm + 3 chosen directions  
**Durable Evidence:** three labeled low-fi prototypes + short comparison notes

## 0–5 min — Skill Warm-up

Inspect teacher low-fi examples (paper or Figma). Note what low-fi **includes** (layout, labels, actions) and what it **skips** (final color, icons, branding).

## 5–9 min — Talk Robin 1

Pairs list differences that matter for users (task clarity, fewer steps, clearer feedback) vs differences that are only visual style.

## 9–14 min — Entry Check

Individually sketch **two** tiny layouts for the same home/start screen in 4 minutes. No color. Mark which better supports the primary goal and why.

## 14–19 min — Core Pattern

Must-know: **Compare alternatives.** One prototype teaches little; three teach trade-offs.

Groups assign:

- Prototype A — simplest / fewest steps  
- Prototype B — most guided / more help text  
- Prototype C — team’s creative alternative  

Each prototype must cover the same core task from Lesson 08.

## 19–30 min — Guided Practice

Create the three low-fi sets (paper or Figma frames):

- start screen;
- main action screen;
- success (or next-step) screen.

Label frames **A / B / C**. Keep components optional; speed matters more than polish.

Quick walkthrough: one teammate tries to complete the task on each prototype while another notes confusion points.

## 30–40 min — Independent Rebuild

Individually complete a comparison card:

| | A | B | C |
|---|---|---|---|
| Helps the need? |  |  |  |
| Confusing spot |  |  |  |
| Keep / drop |  |  |  |

Choose a **primary direction** (or a hybrid) and write one evidence-based reason.

## 40–45 min — Talk Robin 2 + Evidence

Submit three prototypes + comparison card. Announce the direction that moves to evaluation in Lesson 10.

## Success Evidence

Students produce three comparable low-fi prototypes and select a direction using task/need evidence.
