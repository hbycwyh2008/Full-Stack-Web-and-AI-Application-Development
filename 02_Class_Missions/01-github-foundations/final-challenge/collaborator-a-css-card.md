# GitHub Team Launch — Collaborator A: CSS

## Your Role

You are responsible for the page styling.

### Your branch

```text
feature-css
```

### Your Issue

```text
Add page styling
```

## Your Workflow

```text
accept invitation
→ clone shared repo
→ create feature-css
→ edit style.css
→ git status
→ git add
→ git commit
→ git push
→ open PR into main
→ wait for Owner review
→ respond to feedback if needed
→ wait for Owner to merge
→ switch to main
→ pull final version
```

## Your Pull Request Must Explain

- what styling you added;
- why the styling improves the page;
- how you tested it;
- which Issue it closes.

## If the Owner Requests Changes

Update the same `feature-css` branch.

```bash
git add .
git commit -m "Address review feedback"
git push
```

Do **not** open a second Pull Request. The existing PR will update automatically.

## Stop Point

After opening your Pull Request, do not merge it yourself. The Owner / Maintainer is responsible for review and integration into `main`.
