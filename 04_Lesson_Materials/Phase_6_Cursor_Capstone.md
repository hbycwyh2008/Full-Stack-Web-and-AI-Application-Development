# Phase 6: Cursor Capstone

## Phase Goal
Students use an AI-assisted full-stack development workflow with Cursor to build toward the final project.

## Lesson Objectives
- Use the Cursor workflow effectively (planning, generating, reviewing).
- Apply Cursor Rules and AI-assisted debugging.
- Review and verify AI-generated code.

## Required Tools
- Cursor
- Next.js + FastAPI project
- An LLM API key

## Student Tasks
- Implement an AI-assisted full-stack feature (a step toward the AI School Assistant).
- Use Cursor to debug at least one issue.
- Write an AI usage reflection using `01_Student_Templates/AI_Usage_Reflection_Template.md`.

## Teacher Notes
> 我们学习 Cursor 工作流，而不是某个课程里的 Supabase 架构。We study the Cursor workflow, not the Supabase architecture from the reference course. Map Supabase concepts to FastAPI/MongoDB as needed. Stress that students must understand the code they ship.

## Exit Ticket
- Show a feature you built with Cursor.
- Describe one bug you fixed and how.

## Submission Requirement
- An AI-assisted feature + AI usage reflection.
