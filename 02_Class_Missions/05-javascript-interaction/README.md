# 05 — JavaScript + Computational Thinking

## Current Programming Route

Use Scrimba's [Learn JavaScript](https://www.coursera.org/learn/learn-javascript) on Coursera after students have HTML/CSS foundations. Then apply the skills in the [Figma-to-code programming path](programming-foundations-path.md), using each student's tested Figma design as the project.

The required scope is core JavaScript, DOM, events, basic forms, state, testing, and debugging. Add practice meetings as needed. Keep work in the browser; advanced frameworks and backend development are outside this stage.

## Lessons

- [Lesson 16 — Values, State, Functions, and Input→Process→Output](lesson-16-values-state-functions.md)
- [Lesson 17 — Conditions, Iteration, and Algorithm Tracing](lesson-17-control-flow-algorithms.md)
- [Lesson 18 — Arrays, Objects, and Abstraction](lesson-18-arrays-objects-abstraction.md)
- [Lesson 19 — DOM, Events, and Interactive Interfaces](lesson-19-dom-events.md)
- [Lesson 20 — Forms, Persistence, APIs, and Debugging](lesson-20-forms-state-api-debugging.md)

## Core Output

A responsive web page based on the student's Figma design with at least one working JavaScript interaction. Students explain the code, test expected behavior, and make an independent change.
