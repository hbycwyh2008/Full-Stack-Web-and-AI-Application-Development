# Lesson 05 — Needfinding: Understand the Problem Before the Solution

**Length:** 45 minutes  
**HCI stage:** Needfinding  
**OMSCS CS6750 backbone:** **3.1 Methods · 3.2 Ethics · 3.3 Needfinding and Requirements Gathering**  
**Quality control:** Confirmation bias  
**Mission:** Identify what we need to learn about the user, task, and context before proposing a solution.  
**Durable Evidence:** `l05-needfinding-evidence-plan.md`

## 0–5 min — Skill Warm-up

After the OMSCS excerpt, write:

1. What is needfinding trying to discover?
2. Why is starting with a feature risky?
3. What do we need evidence about before designing?

## 5–9 min — Talk Robin 1

Prompt:

> “Students need an AI homework planner.”

Pairs identify:

- the **assumed solution**;
- the possible **user problem**;
- what is still **unknown**.

Rewrite it as a neutral research question.

## 9–14 min — Entry Check

For a new problem, classify each statement as:

- **Known from evidence**
- **Assumption**
- **Unknown to investigate**

Then answer:

> **What evidence could make us change our current idea?**

## 14–19 min — Core Pattern

**Needfinding = understand the user/problem before selecting the solution.**

```text
problem space
→ target user
→ task / context
→ what we know
→ what we assume
→ what we still need to learn
→ evidence plan
```

Three evidence routes:

1. **Ask** — learn about experiences and recent behavior.
2. **Observe** — see what people actually do.
3. **Survey** — compare patterns across more people.

Ethics rule:

> Collect only what is necessary, use consent, and avoid unnecessary personal/private data.

Teacher check:

> The plan should study **users/tasks**, not “whether people like our app.”

## 30–40 min — Independent Rebuild

New scenario:

> “The school wants to improve the cafeteria experience.”

Without proposing a feature, write:

1. target user;
2. task/context;
3. two important unknowns;
4. one evidence method for each;
5. one finding that could change your first assumption.

## 40–45 min — Talk Robin 2 + Evidence

Submit the Needfinding Plan.

Exit statement:

> **“Before designing anything, we still need to learn ______ because ______.”**

## Success Evidence

Students can distinguish a problem from a proposed feature, identify meaningful unknowns, choose evidence methods, and deliberately seek evidence that could challenge an initial assumption.
