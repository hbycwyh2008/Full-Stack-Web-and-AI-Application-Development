# AI Studio B — Learning, Patterns, and Data

**Book spine:** assigned sections on machine learning / neural-network learning.

## Activity
Students examine several examples of input/output behavior and infer what patterns a model might be using. Teams distinguish **training examples, learned pattern, prediction, evaluation, and failure case**.

## Discussion
What does “learn” mean for a machine, and how is that different from saying the system learned like a person?

## Product Connection
For a proposed AI feature, list the data/evidence it would require and one way the available data could misrepresent the user problem.

## Evidence
Commit a concept map connecting data → pattern → prediction → evaluation → limitation.
