# Independent Rebuild — Required Every Lesson (05 Vibe Coding)

**Every class mission in this track includes an independent rebuild.** Follow-along / Udemy / Cursor work lives in one folder; **your memory-only code lives in another.**

---

## Two Folders (Do Not Mix)

| Purpose | Phase 01 path | Phase 02 path |
|---|---|---|
| Follow-along (Udemy, Cursor, notes OK) | `full-stack-practice/` | `vibe-coding/kanban-cursor/` |
| **Independent rebuild (this rule)** | `full-stack-practice/independent-rebuild/lesson-0X/` | `vibe-coding/independent-rebuild/lesson-0X/` |

Copy-paste **from follow-along into rebuild** = not accepted. Rebuild must be a **separate tree** you type yourself.

---

## Rebuild Rules (Non-Negotiable)

Before you start the rebuild block (usually **70–80 min**):

1. **Close all materials** — Udemy, course GitHub, chat notes, Cursor, AI tools, and **do not open** your follow-along project files.
2. **No copy-paste** from follow-along code, screenshots, or prior commits.
3. **Hand-type every line** in the rebuild folder only (keyboard only; no autocomplete from pasted blocks).
4. **No AI** during rebuild — no Cursor Agent, no ChatGPT, no Copilot.
5. Create **`REBUILD.md`** in that lesson folder (template below).
6. **Run or demo** the minimum scope listed in your lesson mission.
7. **Commit separately:** `Independent rebuild lesson-0X (no materials)`.

Teacher may ask you to **explain rebuild code orally** without opening follow-along files.
