# Module 4: React Component Portfolio

## Module Goal

Rebuild the portfolio or profile page as a React project using reusable components and data-driven sections.

Recommended time: **8–10 classes** of 90 minutes.
Fast track: **6 classes**.
Zero-background pacing: **12 classes**.

---

## Required Resource

[Learn React](https://www.coursera.org/learn/learn-react/home/welcome)

---

## Learning Cycle

```text
individual learning → Talk Robin / group discussion → group answer → Entry Points Check → teacher explains only what students do not understand → mission task → exit check → submission of evidence
```

---

## Suggested Class Breakdown

| Class | Focus | Evidence |
|---|---|---|
| 1 | What React changes compared with HTML/CSS/JS | Notes comparing static pages and components |
| 2 | Project setup and file structure | React app opens locally |
| 3 | Components | `Header`, `About`, and `ProjectCard` components |
| 4 | Props | Project data passed into components |
| 5 | Lists and rendering | Multiple projects rendered from an array |
| 6 | State | One interactive component using state |
| 7 | Styling | Portfolio layout polished |
| 8 | Debugging and rebuild | Explain one React error and fix |
| 9–10 | Final portfolio evidence | React portfolio linked from Notion and GitHub |

---

## Required Product

Students create:

```text
react-component-portfolio/
```

Minimum portfolio sections:

1. Header / hero
2. About
3. Skills
4. Projects
5. GitHub and Notion links
6. Reflection or learning timeline

Minimum React components:

1. `Header`
2. `About`
3. `Skills`
4. `ProjectCard`
5. `Footer`

---

## Independent Rebuild

Students must be able to rebuild a small React component without copying:

1. Create a component
2. Import and render it
3. Pass one prop
4. Render a list from an array
5. Explain the difference between HTML elements and React components

---

## Required Evidence

Submit:

1. GitHub folder link
2. Screenshot of the React portfolio running
3. Screenshot or link showing component files
4. Commit history with meaningful React commits
5. Notion portfolio update showing the React project
6. One reflection: “React helps organize a growing portfolio because...”

---

## Success Criteria

Students are successful if:

1. The React project runs locally.
2. The page is organized into components.
3. At least one component uses props.
4. At least one section renders from an array of data.
5. Students can explain component, prop, and state in simple words.
6. The project is connected back to Notion and GitHub evidence.
