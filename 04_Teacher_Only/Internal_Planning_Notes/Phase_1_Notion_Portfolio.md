# Phase 1: Notion Portfolio

**Your goal:** Publish a **Notion portfolio** that showcases your best work and links to your GitHub evidence from Phase 0.

**Template:** [Student_Portfolio_Template.md](../../03_Templates/Student_Portfolio_Template.md)

---

## What You Will Learn

- What a portfolio is and how it differs from your GitHub repo
- How to structure pages: Home, About, Projects, Skills, Reflections, GitHub Links
- How to publish a public Notion link
- How to connect Notion (showcase) with GitHub (evidence)

---

## Why This Matters

**GitHub** shows your process — commits, drafts, revisions.  
**Notion** shows your **best finished story** to teachers, colleges, and programs.

You need both in this course. Phase 1 builds the public layer before AI literacy content (Phase 2).

## In-Class Learning Flow

### 1. Skill Warm-up

**You do:** Compare two sample portfolios (organized vs messy). Write three reasons the organized one is stronger.

**Produce:** Three bullets before Talk Robin.

### 2. Talk Robin Round 1

- **You:** “A portfolio is different from my GitHub repo because…”
- **Partner:** “The sections I will include are…”
- **Together:** One question for the teacher.

### 3. Entry Check

1. What is your GitHub repo link?
2. Name three sections your Notion portfolio will have.
3. Who is the audience for your Notion portfolio?

### 4. Core Pattern

```text
plan sections → create Notion pages → write content → link GitHub → publish public URL → add URL to README
```

### 5. Guided Practice

**You build with class:**

1. Create Notion workspace page for this course
2. Add minimum sections: **Home**, **About Me**, **Projects**, **Skills**, **GitHub Links**, **Reflections**
3. Paste your Phase 0 GitHub link in **GitHub Links**
4. Draft a placeholder **AI School Assistant** project page (final project preview)

### 6. Independent Rebuild

**Checklist:**

- [ ] Seven or more sections with real text (not empty headings)
- [ ] Home and About Me written in **your words**
- [ ] GitHub repo link works
- [ ] Draft project page started
- [ ] You can explain portfolio purpose orally

**Do not** copy another student’s About Me text.

### 7. Talk Robin Round 2 + Evidence

- State the core pattern in one sentence
- Share your public Notion link (or publish step remaining)
- Submit evidence before leaving

## Required Evidence

| Evidence | Where |
|---|---|
| **Public Notion link** | Submit to teacher; add to GitHub `README.md` |
| **Portfolio structure** | Screenshot or share showing sections |
| **GitHub link on portfolio** | GitHub Links section |
| **Reflection** | Short note in `reflections/` or Notion Reflections page |
| **README update** | Commit on GitHub: add Notion link to Portfolio Links |

**Learning evidence types:** program report (portfolio pages), screenshot, reflection, revision record (README commit).
