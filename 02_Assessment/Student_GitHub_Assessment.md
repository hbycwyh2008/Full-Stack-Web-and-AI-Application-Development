# Student GitHub Repository Assessment

Use for **Phase 0** sign-off and ongoing portfolio checks. Assess **organization, documentation, and evidence** — not only code quality.

---

## Criteria

| Criterion | Met? |
|---|---|
| Repository exists and is accessible | ☐ |
| Clear root `README.md` | ☐ |
| Recommended folder structure present (grows over time) | ☐ |
| Commit history exists | ☐ |
| At least one branch created | ☐ |
| At least one pull request opened and merged | ☐ |
| README uses clear Markdown formatting | ☐ |
| Projects organized in correct folders | ☐ |
| Screenshots or evidence included when needed | ☐ |
| Reflections in student's own words | ☐ |
| Repository link submitted correctly | ☐ |
| No secrets (`.env`, API keys) committed | ☐ |

---

## What We Assess

```text
organization
documentation
evidence of learning
project reflection
technical progress
```

We do **not** only assess code. A well-documented repo with clear reflections and folder structure is strong evidence.

---

## Phase 0 Minimum

- Public repo with name `student-portfolio` or `student-name-full-stack-ai-portfolio`
- Root README from `01_Student_Templates/student-root-README-template.md`
- Initial folder structure per `Student_GitHub_Repository_Guide.md`
- PR merged from branch `update-profile`
