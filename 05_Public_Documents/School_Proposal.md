# School Proposal

## Summary

**Full-Stack Web and AI Application Development** is a portfolio-first course that teaches students to build, document, and present real full-stack AI applications. It begins with a formal **AI literacy foundation**, then moves students into AI **application engineering**.

This is not only an AI literacy course. It is an AI application engineering course built on top of AI literacy.

## Alignment with the CS / AI Pathway

This course builds directly on foundational CS/AI concepts — starting with Andrew Ng's AI for Everyone and Generative AI for Everyone — and moves students into applied software development: frontend, backend, databases, and AI integration. It develops skills that transfer to advanced coursework, internships, and post-secondary programs.

## How AI Literacy and Engineering Work Together

| Phase | Focus |
|---|---|
| Phase 0 | AI literacy foundation (concepts, limits, responsible use) |
| Phases 1–5 | Portfolio, GitHub, frontend, backend |
| Phase 6 | AI API + RAG concepts (bridge to final project) |
| Phases 7–9 | Integration, Cursor capstone, AI School Assistant showcase |

AI literacy is not a separate theory track — it connects directly to the final project design and assessment.

## Differentiation from AI Literacy Platforms

| Dimension | AI Literacy Platforms | This Course |
|---|---|---|
| Main goal | AI + CS literacy | AI literacy **plus** application engineering |
| Environment | Platform-based labs | Real development tools |
| Project evidence | Platform activities | GitHub repo + README + portfolio |
| Final output | Classroom activities | Portfolio-ready AI web app |

> AI literacy platforms help students understand AI. This course helps students **understand AI and build AI-powered software**.

## Final Showcase Value

Students conclude with a public demo of an **AI School Assistant** — a working web app grounded in school documents. The showcase demonstrates technical skill, AI literacy, communication, and responsible AI use to the school community.

## Student Portfolio Outcomes

Each student finishes with an AI literacy foundation, a professional portfolio, documented GitHub projects, and a working full-stack application — durable evidence of real, transferable skills.
