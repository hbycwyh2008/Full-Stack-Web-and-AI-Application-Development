# Lesson 08 — Design Alternatives: 3 Directions Before Figma

**Length:** 45 minutes  
**Loop step:** Evidence-backed need → alternatives → user flow  
**CS6750 backbone:** **3.4 Design Alternatives**  
**Mission:** Generate three genuinely different ways to solve the same user need before opening Figma.  
**Durable Evidence:** [L08 submission template](student-templates/l08-three-alternatives-user-flow.md) — 3 alternative sketches + one selected user flow + evidence-based rationale

Bring the Lesson 07 evidence synthesis + micro-requirements.

## 0–5 min — Skill Warm-up

Write:

1. Why is the first interface idea rarely enough?
2. What would make two designs **actually different**, instead of the same layout with different colors?

## 5–9 min — Talk Robin 1

Choose **one evidence-backed user need**.

State:

> “When ___, the user needs to ___ so that ___.”

No features yet.

## 9–14 min — Entry Check

Sketch three 60-second solutions.

They must differ in **interaction structure**, for example:

- list vs calendar;
- guided wizard vs dashboard;
- search-first vs browse-first;
- chat-style vs form-style.

Different colors do not count as different alternatives.

## 14–19 min — Core Pattern

~~~text
Need
→ many ideas
→ 3 distinct directions
→ compare against the need
→ choose one to prototype
~~~

Selection criteria:

1. supports the target task;
2. understandable to the target user;
3. feasible to prototype;
4. worth testing because something is still uncertain.

## 19–30 min — Guided Practice

Create **three paper / gray-box alternatives** for the same task.

Each alternative must show:

- start state;
- primary action;
- 2–4 steps;
- success state.

Then create one comparison table:

| | A | B | C |
|---|---|---|---|
| Supports user need? |  |  |  |
| Number of steps |  |  |  |
| Biggest uncertainty |  |  |  |
| Evidence / reason |  |  |  |

## 30–40 min — Independent Rebuild

Choose one direction or one deliberate hybrid.

Draw the **primary user flow**:

~~~text
Start → Step 1 → Step 2 → Step 3 → Success
~~~

Add one possible wrong turn / recovery.

## 40–45 min — Talk Robin 2 + Evidence

Submit:

- A / B / C sketches;
- comparison table;
- selected user flow.

Exit statement:

> “We chose ___ because ___ evidence suggests ___; we still need to test ___.”

## Success Evidence

Students explore multiple interaction structures before committing to one, and their selected direction is tied to a user need rather than visual preference.
