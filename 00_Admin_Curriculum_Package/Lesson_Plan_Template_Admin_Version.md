## 5. Mastery Check

Students demonstrate mastery when they can:

- [ ] **Explain** the concept in their own words
- [ ] **Rebuild** a core pattern without copying
- [ ] **Debug** a small error independently
- [ ] **Modify** the code for a new requirement
