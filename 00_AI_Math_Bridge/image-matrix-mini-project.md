# Image Matrix Mini Project (Lesson 10)

## Goal

Connect linear algebra to **computer vision** with a small hands-on project.

## Tasks

1. Load or create a simple image matrix (e.g. with PIL, OpenCV, or matplotlib + NumPy).
2. Inspect pixel values (print a small region).
3. Convert to grayscale if appropriate.
4. Modify some pixel values (e.g. brighten a region, simple filter).
5. Display the image before and after.
6. Write a short reflection in `ai-math-bridge/README.md` or a separate file.
7. Save notebook as `image-as-matrix-lab.ipynb`.
8. Add screenshots to `ai-math-bridge/screenshots/`.

## Reflection Prompts

- How is the image stored as numbers?
- What changed when you edited pixels?
- How could this connect to AI or CV?
