# Module 3: JavaScript Interactive Profile

## Module Goal

Use JavaScript to add behavior to the digital business card or profile page.

Recommended time: **8–10 classes** of 90 minutes.
Fast track: **6 classes**.
Zero-background pacing: **12 classes**.

---

## Required Resource

[Learn JavaScript](https://www.coursera.org/learn/learn-javascript/home/welcome)

---

## Learning Cycle

```text
individual learning → Talk Robin / group discussion → group answer → Entry Points Check → teacher explains only what students do not understand → mission task → exit check → submission of evidence
```

---

## Suggested Class Breakdown

| Class | Focus | Evidence |
|---|---|---|
| 1 | What JavaScript does on a page | Short notes comparing HTML, CSS, and JavaScript |
| 2 | Variables and strings | Student profile data stored in variables |
| 3 | Functions | Button or function that updates text |
| 4 | Conditions | Simple skill-level or goal message |
| 5 | DOM selection | JavaScript changes page content |
| 6 | Events | Button click interaction works |
| 7 | Arrays or lists | Skills or projects rendered from data |
| 8 | Debugging and rebuild | Explain one bug and how it was fixed |
| 9–10 | Polish and submit | Final interactive profile evidence |

---

## Required Product

Students extend their previous project or create:

```text
javascript-interactive-profile/
```

Minimum files:

```text
index.html
style.css
script.js
README.md
```

Minimum interactions:

1. A button that changes visible page content
2. A skills or project list controlled by JavaScript data
3. A message that changes based on a condition
4. At least one comment explaining a non-obvious line of code

---

## Independent Rebuild

Students must rebuild one small interaction without the tutorial:

1. Select an element
2. Write a function
3. Attach a click event
4. Change text or style on the page
5. Explain the flow: “When the user clicks..., JavaScript...”

---

## Required Evidence

Submit:

1. GitHub folder link
2. Screenshot or short recording of the interaction
3. Screenshot or link showing `script.js`
4. Commit history with meaningful JavaScript commits
5. Notion portfolio update showing the JavaScript project
6. One reflection: “JavaScript makes my page interactive because...”

---

## Success Criteria

Students are successful if:

1. `script.js` is connected and runs.
2. The page changes in response to user action.
3. JavaScript code is readable and not only copied.
4. Students can explain variables, functions, and events in simple words.
5. The project is linked from the Notion portfolio.
