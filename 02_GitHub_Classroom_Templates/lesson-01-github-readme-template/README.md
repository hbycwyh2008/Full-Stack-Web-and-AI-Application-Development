# GitHub README Portfolio Setup

## Goal

Create a professional README for your portfolio repository.

## What You Will Build

A README.md with sections: About Me, Skills, Projects, Learning Goals.

## Starter Files

See the `starter_files/` folder:

- README scaffold, profile placeholder

## Required Tasks

Write all sections in your own words; add at least 3 skills; link one project folder.

## Evidence to Submit

README.md committed to your repo; screenshot of rendered README; reflection.

## Reflection Questions

1. What is the difference between a repo and a README?
2. What was the hardest part of this assignment?
3. How did you use AI (if at all)? What did you change after AI suggestions?

## Extension Challenge

Add a Mermaid diagram or table of projects.
