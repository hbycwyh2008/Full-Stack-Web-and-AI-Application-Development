# Lesson 4: Oh My Git! for Commit and History

**Duration:** 80 minutes  
**Target mastery after lesson:** Level 2–3 (metaphor → real GitHub)

---

## 1. Lesson Goal

Students use **Oh My Git!** as a **supporting activity** to understand commits and history, then connect the game timeline to **real GitHub commit history** in `cs-learning-log`.

**Do not** require branches, merge, or index sections in this beginner unit.

---

## 2. Resources (Selected)

| Resource | URL | Use |
|---|---|---|
| Oh My Git! | https://ohmygit.org/ | Lesson activity — **intro levels only** |
| A brief introduction to Git for beginners | https://www.youtube.com/watch?v=r8jQ9hVA2qs | Optional warm-up review |

### Oh My Git — Required levels only

1. **Living dangerously**
2. **Making backups**
3. **The command line**
4. **Your first commit**

**Do not assign:** branch levels, merge, index deep sections.

---

## 3. Core Vocabulary

| Term | Definition |
|---|---|
| **Snapshot** | A saved state of files (like a commit) |
| **Timeline** | Sequence of snapshots — like commit history |
| **Backup** | Saving work so you can return to an earlier state |
| **Metaphor** | Game idea that maps to real Git behavior |

---

## 4. Core Pattern

```text
game timeline → commit history → learning evidence
```

---

## 5. 80-Minute Lesson Flow

Standard 8-block flow.

**Note:** Balance screen time — game is warm-up/guided, GitHub evidence is required exit.

---

## 6. Skill Warm-up (0–20 min)

**Task:** Play **Living dangerously** and **Making backups** (or teacher demo).

**While playing, note:**

- What happens when you don’t save/back up?
- How is “backup” in the game like a **commit**?

Stop at 20 min even if level unfinished — move to Entry Check.

---

## 7. Entry Check (20–30 min)

1. In Oh My Git, what problem does “making backups” solve?
2. How is the game timeline like GitHub’s Commits tab?
3. Open your real repo Commits tab — how many commits do you have?
4. Why is the game **not** enough evidence by itself?
5. What will you add to `lesson-04/notes.md` today?

---

## 8. Talk Robin Round 1 (30–34 min)

- A: “A commit is like ___ in the game because…”
- B: “Real GitHub history shows evidence because…”
- Shared: One level we should play next (teacher time).

---

## 9. Teacher Pattern Explanation (34–45 min)

### Connect game → GitHub

| Game idea | Real GitHub |
|---|---|
| Backup / snapshot | Commit |
| Timeline of backups | Commit history |
| Descriptive backup label | Commit message |
| Seeing old state | Viewing past commit |

**Branches in game:** mention only — “we learn later.”

### Today’s GitHub work

1. Screenshot Oh My Git level completion
2. Create `lesson-04/notes.md`:
   - Which levels you played
   - How game maps to Commits tab
   - One new insight about history as evidence
3. Commit: `Add lesson-04 notes connecting Oh My Git to commit history`
4. Optional: add screenshot to `lesson-04/` (if school policy allows images)

---

## 10. Guided Practice (45–60 min)

**Split:**

- **45–52 min:** Students play **The command line** + **Your first commit** (or teacher-paced demo)
- **52–60 min:** Everyone writes `lesson-04/notes.md` draft; teacher shows Commits tab alongside game screenshot

---

## 11. Independent Rebuild (60–72 min)

**Checklist:**

- [ ] Completed **at least 3** of the 4 assigned intro levels (or teacher alternative)
- [ ] Screenshot of game progress saved/submitted
- [ ] `lesson-04/notes.md` has 3+ sentences connecting game to GitHub
- [ ] Meaningful commit on `cs-learning-log`
- [ ] Can explain connection without reading notes word-for-word

---

## 12. Talk Robin Round 2 (72–76 min)

- A: “Game timeline → commit history means…”
- B: “My evidence on GitHub that proves learning is…”
- Shared: Exit Evidence.

---

## 13. Exit Evidence (76–80 min)

1. Oh My Git screenshot
2. Link to `lesson-04/notes.md`
3. One sentence: **How is the game timeline like GitHub history?**

---

## 14. Mastery Check

| Level | Indicator |
|---|---|
| 0 | Played game only |
| 2 | Explains mapping while looking at Commits + notes |
| 3 | Notes + commit without copying teacher paragraph |
| 5 | Helps peer see Commits tab story |

---

## 15. Common Mistakes

- Playing branch levels off-unit
- Screenshot only — no `lesson-04/notes.md`
- Notes say “game was fun” with no GitHub connection
- Commit message `lesson 4`

---

## 16. Optional Extension

- Preview Lesson 5 local commands on cheatsheet
