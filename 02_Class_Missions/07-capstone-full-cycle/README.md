# 07 — Capstone: Run the Full Software Development Cycle

The final project is **not required to be an AI app**. It must solve a researched user problem and demonstrate the complete workflow students have practiced.

## Required Final Evidence

1. user research and synthesis;
2. problem statement and measurable requirements;
3. GitHub issue/branch/PR/review history;
4. Figma user flow, wireframes, and high-fidelity prototype;
5. HTML/CSS/JavaScript implementation;
6. usability + accessibility/QA evidence;
7. deployed release and release notes;
8. retrospective showing what changed across the lifecycle;
9. AI literacy product-decision memo — whether or not the project uses AI.
