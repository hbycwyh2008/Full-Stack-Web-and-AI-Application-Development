# Project README Template

Every project repository must include a `README.md`. Copy the template below into your project and fill in each section.

---

```markdown
# Project Title

## Overview
Briefly explain what this project does.

## Problem
What problem does this project solve?

## Features
- Feature 1
- Feature 2
- Feature 3

## Tools Used
- Next.js
- FastAPI
- Python
- MongoDB
- Cursor

## Screenshots
Add screenshots here.

## How It Works
Explain the data flow:

Frontend → Backend → Database / AI API → Response

## What I Learned
Explain the key concepts you learned.

## AI Usage
- What AI helped generate
- What you modified yourself
- What you tested
- What you still do not fully understand

## Links
- Live demo:
- GitHub repo:
- Portfolio page:
```

---

## Tips

- Write the Overview and Problem sections first — they keep your project focused.
- Add screenshots once you have a working version.
- Be specific in **AI Usage**: graders want to see what you understood, not just what AI produced.
