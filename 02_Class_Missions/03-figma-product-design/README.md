# 03 — Figma Product Design

Students continue the design loop started in HCI needfinding:

```text
Initial Needfinding (HCI 05–07)
  → Brainstorm Alternatives          (Lesson 08)
  → Create 3 Prototypes              (Lesson 09)
  → Evaluate + Further Needfinding   (Lesson 10)
  → Brainstorm Again → Higher-Fidelity Prototype → Evaluate Again (Lesson 11)
```

Figma is a medium for product reasoning, not only button-click training.

## Classroom flow

Same seven poster blocks as every class:

```text
Skill Warm-up → Talk Robin 1 → Entry Check → Core Pattern
→ Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence
```

## Core outputs

brainstorm board + chosen direction → **3 low-fi prototypes** → peer-eval notes + new needfinding questions → clickable high-fi prototype + second eval / revision log.

## Standard

Teams must show more than one alternative before polishing a single screen. Evaluation uses user tasks and evidence, not “I like the color.”
