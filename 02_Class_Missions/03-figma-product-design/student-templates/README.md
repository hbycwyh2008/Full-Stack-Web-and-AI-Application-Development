## Submission rule

The student repository stores the **reasoning evidence**. Figma stores the actual design.

Each Markdown file should contain the current Figma URL and any required screenshots. Do not duplicate the entire Figma file into GitHub.

## Evidence rule

A visual change does not count as an evidence-driven revision unless the student can point to:

1. a Core-3 design problem, or
2. something a tester actually did / said.

## Exit gate

L11 contains the **Design → Build Gate**. Students should not implement a known-bad interaction in HTML/CSS merely because the prototype looks polished.
