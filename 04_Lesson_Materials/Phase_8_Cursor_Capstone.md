# Phase 8: Cursor Capstone

## Phase Goal
Use Cursor to build or improve a full-stack feature toward the AI School Assistant, while staying responsible for understanding and testing the code.

## Key Concepts
- Planning before prompting; writing a clear Cursor prompt.
- Reading generated code, testing, and debugging.
- Documenting what AI changed and writing an AI usage reflection.

> Cursor can accelerate development, but the student remains responsible for understanding and testing the project.

## Required Student Output
- An AI-assisted full-stack feature (for example, an `/ask` endpoint or a chat UI).
- Evidence of testing and debugging with Cursor.
- An AI usage reflection.

---

## Suggested Lesson Count
3 lessons.

## Lesson Sequence

### Lesson 1: Plan Before You Prompt
- **Goal:** Plan a feature and write a clear Cursor prompt.
- **Warm-up:** "What goes wrong if you ask AI to 'build my whole app' in one sentence?"
- **Mini Lesson:** Review the AI Usage Policy and Responsible AI Checklist. How to break a feature into small steps and write a specific prompt. Look at the teacher demo as a model.
- **Guided Practice:** As a class, plan one feature and write a prompt together.
- **Independent Work:** Write a plan and a first Cursor prompt for a feature.
- **Exit Ticket:** What are the small steps of your feature?
- **Homework:** Refine your plan and prompt.

### Lesson 2: Build, Read, and Test
- **Goal:** Generate code with Cursor, then read and test it.
- **Warm-up:** "Explain this line" using a snippet Cursor produced.
- **Mini Lesson:** Reading generated code, testing it, and spotting things AI got wrong.
- **Guided Practice:** Build part of the feature with Cursor; test it together; find one issue.
- **Independent Work:** Implement and test your feature; note what AI changed.
- **Exit Ticket:** Name one thing you verified worked.
- **Homework:** Fix at least one bug using Cursor and record how.

### Lesson 3: Debug, Document, Reflect
- **Goal:** Finish the feature, document it, and reflect on AI use.
- **Warm-up:** "What is one bug you fixed and how did you find it?"
- **Mini Lesson:** Documenting AI usage honestly; connecting the feature to the AI School Assistant.
- **Guided Practice:** Review a partner's feature and ask them to explain one part.
- **Independent Work:** Write the AI usage reflection and commit the feature to GitHub.
- **Exit Ticket:** What part of your feature can you fully explain? What part still needs review?
- **Homework:** Polish and commit; prepare for the final showcase.

## Submission Requirements
- [ ] Working AI-assisted feature.
- [ ] Documented bug fix using Cursor.
- [ ] AI usage reflection completed.
- [ ] Code committed to GitHub.

## Common Student Problems
- Accepting AI code without testing → require evidence of testing.
- Over-scoping the feature → keep it small and focused.
- Not disclosing AI usage → reinforce the AI Usage Policy.
- Getting stuck in prompt loops → teach: plan, prompt, read, test, repeat.

## Teacher Notes
> 学生用 Cursor 加速，但必须理解和测试代码。Students use Cursor to accelerate, but must understand and test the code. Use the teacher demo (`06_Starter_Code/teacher-demo-ai-school-assistant/`) and the Teacher Demo Walkthrough lesson before this phase so students have a concrete model.

## AI Lens Reflection
Ask students: *"What did Cursor get wrong or almost wrong, and how did you catch it?"* Save the answer in Learning Notes.
