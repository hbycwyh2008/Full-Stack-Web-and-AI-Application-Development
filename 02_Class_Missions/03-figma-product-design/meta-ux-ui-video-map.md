# Meta UX/UI Video Map — Lessons 09–11

**Course:** Meta — *Principles of UX/UI Design*  
**Coursera:** https://www.coursera.org/learn/principles-of-ux-ui-design  
**Use rule:** one short required video per class. The video introduces the pattern; class practice builds the skill.

This map intentionally does **not** assign the full Coursera course.

## Required sequence

| Lesson | Module | Required video | Approx. time | Why this one |
|---|---|---|---:|---|
| **L09** | Module 3 — Applied Design Fundamentals | **Frames, layers and basic shapes** | 5 min | Enough Figma structure to begin a low-fi wireframe immediately |
| **L10** | Module 3 — Applied Design Fundamentals | **Usability testing** | 4 min | Directly prepares students to run a task test without coaching |
| **L11** | Module 4 — Designing your UI | **Moving from design to prototyping** | 4 min | Connects screens into an interactive prototype |

## Optional / teacher-selected support

Use only when a class actually needs it.

| Need | Module | Video / resource | Approx. time | Use |
|---|---|---|---:|---|
| First-ever Figma orientation | Module 1 | **Getting started with Figma** | 5 min | Substitute for the L09 required clip if students cannot yet navigate Figma |
| Wireframe concept is weak | Module 3 | **Wireframing** | 4 min | Reinforce low-fi structure; do not stack automatically with the required clip |
| Designer review / heuristic idea is weak | Module 2 | **Evaluating design** | 3 min | Teacher support before the Core-3 review |
| Text hierarchy is weak | Module 3 | **Type and text** | 5 min | Optional visual/readability support |
| Grid / layout is weak | Module 3 | **Grids and constraints** | 4 min | Optional alignment/layout support |
| High-fi visual quality is weak | Module 4 | **Make it beautiful** | 6 min | Optional after task flow works |
| Prototype testing / animation extension | Module 4 | **Animate and test your prototype** | 5 min | Optional after students can already connect screens |

## What is deliberately not required

Do not require students to finish:

- all Module 1 UX theory;
- all Module 2 readings / quizzes;
- all Module 3 exercises;
- full design-system theory;
- micro-interactions / animation;
- the course certificate.

The course is a **resource spine**, not the curriculum.

## Classroom transfer rule

~~~text
Required clip
→ teacher model
→ guided design-along / test-along
→ independent rebuild
→ apply to student's own project
→ save evidence
~~~

If students can imitate the clip but cannot rebuild the pattern on their own design, the skill is not yet mastered.
