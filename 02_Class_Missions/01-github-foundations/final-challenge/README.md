## Recommended Use

1. Assign teams of three.
2. Give each student only the role card needed for their role.
3. Use the Student Mission as the shared progression.
4. Use the Teacher Guide mission gates to unlock the next stage.
5. Grade GitHub artifacts rather than screenshots whenever possible.

The challenge is intentionally designed so scaffolding decreases as students progress. The final evidence is the repository history plus the deployed GitHub Pages site.
