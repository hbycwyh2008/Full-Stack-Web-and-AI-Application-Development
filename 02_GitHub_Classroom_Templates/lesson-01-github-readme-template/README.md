# GitHub README Portfolio Setup

## Goal

Create or update a GitHub README that introduces yourself, this course, and where your learning evidence will live.

## What You Will Build

A root `README.md` in your personal portfolio repository with sections for:

- your name and short introduction
- the course you are taking
- skills you are building
- space for future projects
- learning goals for this term

## Starter Files

Open the `starter_files/` folder:

- `README.md` — scaffold with section headings (replace all placeholder text)

Copy the scaffold into your portfolio repository root, then edit in **your own words**.

## Required Tasks

1. Create or open your personal portfolio repository on GitHub.
2. Copy the starter `README.md` scaffold into the root of your repo.
3. Fill in every section in your own words (do not leave placeholder text).
4. Add at least **three skills** you are learning or want to learn.
5. Commit with a **meaningful commit message** (for example: `Add portfolio README with course intro`).
6. Push to GitHub and confirm the README displays on your repo page.

## Evidence to Submit

- [ ] `README.md` committed to your GitHub repo
- [ ] Meaningful commit message visible in commit history
- [ ] Screenshot of your rendered README **or** link to your GitHub repo
- [ ] Completed `reflection.md`

## Reflection Questions

1. What is the difference between a GitHub repository and a README file?
2. What was the hardest part of writing your README in your own words?
3. Did you use AI for help? If yes, what did you change after AI suggestions?

## Extension Challenge

Add a simple table of projects (even if some rows say “coming soon”) or a bullet list of tools you plan to learn.
