# 00 — Course Orientation and the Software Lifecycle

The course begins with the idea that **software development is much larger than coding**. Students inspect products, model the lifecycle, and learn what evidence they will produce throughout the year.

## Lessons

- [Lesson 00 — Software Is More Than Code](lesson-00-software-is-more-than-code.md)
- [Lesson 01 — Product Teardown: Trace the Lifecycle](lesson-01-product-teardown-lifecycle.md)

## Core Outputs

- personal software-development lifecycle map;
- team product teardown board;
- first GitHub learning evidence.
