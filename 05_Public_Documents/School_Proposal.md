# School Proposal

## Summary

**Full-Stack Web and AI Application Development** is a portfolio-first course that teaches students to build, document, and present real full-stack AI applications. It complements existing AI literacy offerings by focusing on AI **application engineering**.

## Alignment with the CS / AI Pathway

This course builds directly on foundational CS/AI concepts and moves students into applied software development: frontend, backend, databases, and AI integration. It develops skills that transfer to advanced coursework, internships, and post-secondary programs.

## Final Showcase Value

Students conclude with a public demo of an **AI School Assistant** — a working web app grounded in school documents. The showcase demonstrates technical skill, communication, and responsible AI use to the school community.

## Student Portfolio Outcomes

Each student finishes with a professional portfolio, documented GitHub projects, and a working full-stack application — durable evidence of real, transferable skills.
