# Student Start Here — Software Design, Development & AI

## What You Are Learning

This course begins with a question that is bigger than coding:

> **What is computer science?**

You will learn that computer science studies computation, information, algorithms, systems, interactions, and the effects of computing. Programming is one important part of that work.

You will then repeatedly work through:

```text
problem → research → requirements → Figma design → GitHub plan
→ HTML/CSS/JavaScript build → review/test → release → improve
```

Later, you will complete a focused AI literacy unit using Melanie Mitchell's _Artificial Intelligence: A Guide for Thinking Humans_. The reading is studied as AI literacy; you do not have to force it into every web project.

## Start

1. Open [02_Class_Missions/README.md](02_Class_Missions/README.md).
2. Your teacher will identify the current lesson.
3. Keep evidence in your GitHub project/repository as instructed.
4. Use Figma links and research/testing evidence alongside code.

## AP CSP

This course gives you a foundation for AP Computer Science Principles, but it is **not the AP CSP course**. In Lesson 00 you will discover which AP CSP ideas this course prepares you for and what you will still learn later.

## Important

A finished screen is not enough. A working program is not enough. You must be able to show why the product exists, what users said/did, why the design changed, how code was reviewed/tested, and what changed after evidence.

Python and advanced frameworks are optional extensions, not the main pathway.
