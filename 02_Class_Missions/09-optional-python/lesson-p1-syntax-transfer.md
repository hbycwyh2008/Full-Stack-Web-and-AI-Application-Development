# Optional Python 1 — Syntax Transfer from JavaScript

## Mission
Transfer programming ideas already learned in JavaScript into Python syntax.

Students compare variables, strings/numbers/booleans, `if`, loops, functions, parameters, return values, and basic input/output. The main activity is a side-by-side translation challenge: predict behavior first, then run and debug.

## Evidence
Commit a short `js-to-python.md` comparison plus two small Python functions with tests/examples.
