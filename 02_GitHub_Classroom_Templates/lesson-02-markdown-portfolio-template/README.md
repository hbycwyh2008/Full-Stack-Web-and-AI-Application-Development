# Markdown Portfolio Page

## Goal

Use Markdown to structure a basic portfolio page with headings, lists, links, images, and a reflection section.

## What You Will Build

A Markdown file (for example `portfolio.md`) in your GitHub repository with:

- clear headings (H1, H2, H3)
- a bullet list of skills or interests
- at least one **link** (to GitHub, a project, or a resource)
- at least one **image or screenshot placeholder**
- a **Reflection** section you will fill in after you finish

## Starter Files

Open the `starter_files/` folder:

- `README.md` — how to use the starter files
- `portfolio.md` — Markdown scaffold to copy into your repo

## Required Tasks

1. Copy `portfolio.md` into your portfolio repository (for example `profile/portfolio.md` or `portfolio.md`).
2. Replace all placeholder text with your own content.
3. Use at least one Markdown link and one image syntax line (screenshot or placeholder image path).
4. Complete the Reflection section at the bottom.
5. Commit with a meaningful message and push to GitHub.
6. Make at least **two commits** if you revise your work (shows revision record).

## Evidence to Submit

- [ ] Markdown portfolio file in your GitHub repo
- [ ] At least one working **link** in the file
- [ ] At least one **image or screenshot placeholder** in the file
- [ ] Reflection section completed
- [ ] Meaningful **commit history** (not one single upload)
- [ ] Completed `reflection.md`

## Reflection Questions

1. Which Markdown syntax was new or confusing for you?
2. How is a Markdown portfolio page different from your repo README?
3. Did you use AI for help? What did you edit yourself before submitting?

## Extension Challenge

Add a table of projects or a second-level skills list grouped by topic (web, AI, tools).
