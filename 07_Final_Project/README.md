# Final Project — User-Centered Software Product

The final project demonstrates the **complete software-development lifecycle**. It is not required to be a full-stack framework project or an AI application.

See [Final Project Specification](Final_Project_Specification.md).

If a team believes AI genuinely improves the validated user problem, use [Optional AI Extension](Optional_AI_Extension.md) as an additional decision/checklist — not as a requirement.
