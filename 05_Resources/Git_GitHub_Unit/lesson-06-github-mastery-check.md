# Lesson 6: GitHub Mastery Check

**Duration:** 45 minutes  
**Target mastery:** Level 3 minimum; Level 4–5 for strong mastery

---

## 1. Lesson Goal

Students **prove** GitHub mastery through independent work, meaningful commit, written answers, oral explanation, and self-assessed level (3, 4, or 5).

---

Handouts: `github-mastery-rubric.md`, `exit-evidence-checklist.md`, `mastery-levels.md`

**No new external resources** — this lesson is evidence and explanation.

Review unit vocabulary: repository, README, commit, commit history, push, evidence, mastery levels.

independent task → meaningful commit → evidence submission → oral explanation

## 6. Skill Warm-up (0–20 min)

**Unit pattern review** — students write on paper:

1. Lesson 1 pattern
2. Lesson 2 pattern
3. Lesson 3 pattern
4. Lesson 5 commands (or web equivalent)

Pair check — no devices yet.

---

## 7. Entry Check (20–30 min)

Without opening notes, write short answers:

1. What is a repository?
2. What is a commit?
3. What is commit history?
4. Saving vs committing vs pushing?
5. Why GitHub evidence in this course?

**Self-score:** How many without guessing? (0–5)

---

## 8. Talk Robin Round 1 (30–34 min)

- A: Answer question 2 (commit) with example from **your** repo
- B: Answer question 4 (save/commit/push) with example
- Shared: Which question is hardest?

---

## 9. Teacher Pattern Explanation (34–45 min)

### Independent task

Create file:

```text
mastery-check/final-github-practice.md
```

Must answer **in student’s own words** (reference `cs-learning-log`):

1. What is a repository?
2. What is a commit?
3. What is commit history?
4. What is the difference between saving, committing, and pushing?
5. Why is GitHub evidence important in this course?

### Commit

Meaningful message example: `Add final GitHub mastery practice answers`

### Mastery levels for this check

| Level | How demonstrated |
|---|---|
| **3** | Completes file with checklist / rubric visible |
| **4** | Completes without full instructions or solution code |
| **5** | Explains orally, debugs, helps peer locate problem |

### Oral defense

Teacher may ask:

- “Show your last commit — what changed?”
- “Why is `update` weak?”
- “What if you saved locally but GitHub is old?”

### AI policy

If answers are generic AI text, student must **revise** and explain orally.

---

## 10. Guided Practice (45–60 min)

- Create `mastery-check/` folder
- Draft answers — teacher checks for personal examples (repo name, commit count, folder structure)
- Students must cite **their** evidence: “In my `cs-learning-log`, I have X commits…”

---

## 11. Independent Rebuild (60–72 min)

**Checklist:**

- [ ] `mastery-check/final-github-practice.md` complete (all 5 questions)
- [ ] Answers use own words + personal repo examples
- [ ] Committed with meaningful message
- [ ] Prepared oral 30-second answers
- [ ] Self-assessment sentence drafted

**Level 4 students:** close cheatsheet and rubric after reading questions once.

**Level 5 students:** after finishing, help assigned peer check Commits tab (hints only).

---

## 12. Talk Robin Round 2 (72–76 min)

Practice oral responses — 45 sec each:

- A: Question 3 (commit history)
- B: Question 5 (why evidence matters)
- Shared: “My current level is ___ because ___.”

---

## 13. Exit Evidence (76–80 min)

1. Link to `mastery-check/final-github-practice.md`
2. Screenshot of **final commit** on Commits tab
3. Sentence: **“My current GitHub mastery level is Level ___ because…”**
4. Oral check (teacher cold call 2–3 students)

Submit via `rubrics/exit-evidence-checklist.md` Lesson 6 section.

---

## 14. Mastery Check (Summative)

Use `rubrics/github-mastery-rubric.md` for final level assignment.

**Unit completion minimum:** Level 3 on rubric + all lesson exit evidence.

---

## 15. Common Mistakes

- Copied definitions from internet with no personal example
- File in wrong path (`final-github-practice.md` in root only — accept if clear, prefer `mastery-check/`)
- Commit `done` or `final`
- Cannot orally explain own answer when called
