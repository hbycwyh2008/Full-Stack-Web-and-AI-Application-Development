# Git & GitHub Unit — One-Page Student Summary

**Course:** Full-Stack Web and AI Application Development

---

## What This Unit Is About

You will use **GitHub** to prove **how you learn** — not just to hand in files.

**Your repo:** `cs-learning-log`

---

## How Every Class Works (80 Minutes)

1. **Skill Warm-up** — short video/reading (not full course completion)
2. **Entry Check** — quick questions on your own
3. **Talk Robin 1** — pair talk (45s + 45s + 30s + teacher call)
4. **Teacher Pattern** — learn the core pattern for today
5. **Guided Practice** — follow with teacher help
6. **Independent Rebuild** — you do it with checklist, not full copy
7. **Talk Robin 2** — summarize pattern + evidence
8. **Exit Evidence** — submit proof (link, screenshot, sentences)

---

## Six Lessons

| # | Topic | Pattern |
|---|---|---|
| 1 | Course workflow + first repo | repo → README → commit → history |
| 2 | README + commit history | small change → meaningful commit |
| 3 | File organization | folder → file → write → commit |
| 4 | Oh My Git! + history | game → real GitHub history |
| 5 | Local Git (VS Code / terminal) | status → add → commit → push |
| 6 | Mastery check | independent task → evidence → oral |

---

## What Success Looks Like

- Clear README and organized `lesson-XX/notes.md` files
- **Many commits** with **meaningful messages**
- You can explain commits and history **orally**
- You debug before asking for help
- You submit Exit Evidence every lesson

---

## What Does NOT Count as Success

- Watching videos without rebuilding
- Copy-pasting README from AI without understanding
- One commit called `final` at the end
- Dumping random files with no folders

---

## Mastery Levels (Target: Level 3+)

0 Exposure → 1 Copy → 2 Explain looking → **3 Rebuild checklist** → 4 Rebuild blind → 5 Modify/debug/help

---

## Key Principles

- Watching ≠ mastery. Copying ≠ mastery.
- Debugging is learning, not failure.
- AI can hint — **you** must understand and revise.
- Evidence: GitHub commits, screenshots, learning log, reflections.
