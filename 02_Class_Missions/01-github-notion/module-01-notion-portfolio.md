# Module 1: Notion Portfolio

## Module Goal

Publish a Notion portfolio that introduces the student, links to GitHub evidence, and becomes the public showcase for future projects.

Recommended time: **2 classes** of 90 minutes.

---

## Required Resource

[Notion Masterclass: Build a Portfolio Website from Scratch](https://www.classcentral.com/classroom/youtube-notion-masterclass-build-a-portfolio-website-from-scratch-for-free-143690/6413e424df7d5)

Direct video:

[How to Build a FREE Website with Notion (Full Tutorial)](https://www.youtube.com/watch?v=w8NQU9k4afM)

Suggested split:

1. Class 1: 00:00–24:36 — page structure, blank page, hero, portfolio section
2. Class 2: 24:36–41:48 — supporting sections, publishing, public link checks

---

## Learning Cycle

```text
individual learning → Talk Robin / group discussion → group answer → Entry Points Check → teacher explains only what students do not understand → mission task → exit check → submission of evidence
```

---

## Class 1 Mission

Students build the portfolio structure:

1. Hero / welcome section
2. About Me
3. Learning Projects
4. GitHub Evidence
5. Skills
6. Reflections

Required evidence:

1. Screenshot of the Notion page structure
2. Screenshot or link showing the GitHub Evidence section
3. One sentence explaining how Notion is different from GitHub

---

## Class 2 Mission

Students publish and connect the portfolio:

1. Add FAQ, contact / next steps, or GitHub learning reflection
2. Publish the Notion page
3. Test the public link
4. Add the Notion link to the GitHub `README.md`
5. Commit with a meaningful message

Required evidence:

1. Public Notion portfolio link, or teacher-viewable link if public publishing is blocked
2. Screenshot of the published homepage
3. GitHub `README.md` showing the Notion link
4. Commit history showing the README update

---

## Success Criteria

Students are successful if:

1. The Notion portfolio opens correctly.
2. The page includes real student writing, not empty headings.
3. Notion links to GitHub.
4. GitHub links back to Notion.
5. Students can explain: “Notion shows my story; GitHub proves my work.”

---

## Fast Track Option

If students finish in one 90-minute class, use the remaining time for a GitHub evidence audit before starting HTML/CSS.
