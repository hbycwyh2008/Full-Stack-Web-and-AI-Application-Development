# Student Start Here

**Course:** Full-Stack Web and AI Application Development

Welcome. Open this file first. It tells you where to go every day and where your work lives.

---

## What This Course Is

A **portfolio-first**, **evidence-based**, **mastery-focused** course in full-stack web and AI application development.

You will build real projects, document your process, and prove you can **explain, rebuild, debug, modify, and apply** what you learn — not just watch, copy, or run code once.

**Final project:** [AI School Assistant](07_Final_Project/Final_Project_Specification.md)

---

## What You Do Every Class

Each **90-minute** class follows the same flow:

1. **Self Learning / Skill Warm-up**
2. **Talk Robin 1**
3. **Group Answer**
4. **Entry Points Check**
5. **Teacher Explanation / Core Pattern**
6. **Guided Practice**
7. **Independent Rebuild**
8. **Talk Robin 2 + Evidence**

## What Mastery Means

![Mastery Level](08_Public_Documents/posters/mastery-level.png)

**Running code once is not mastery.**

You demonstrate **mastery** when you can:

1. **Explain** — in your own words
2. **Rebuild** — **independent rebuild** without copying full solutions
3. **Debug** — read errors and fix step by step
4. **Modify** — adapt the pattern to a new task
5. **Apply** — use the idea in a later project

Levels: [mastery-levels](02_Class_Missions/shared/mastery-levels.md)

## How AI May Be Used

![AI Use Policy](08_Public_Documents/posters/ai-use-policy.png)

AI is allowed as a **learning tool**, not a **shortcut**.

**May:** explain concepts, debug, hints, review, practice  
**May not:** complete entire tasks for you, submit work you cannot explain, skip **Independent Rebuild**

Full rules: [AI Use Policy for Students](01_Student_Start/04_AI_Use_Policy_For_Students.md)
