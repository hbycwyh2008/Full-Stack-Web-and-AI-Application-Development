# AI Math Bridge: Linear Algebra for AI

**Phase 3** — practical math intuition for AI, ML, and computer vision. Not a full proof-based linear algebra course.

## Module Goal

Students understand that AI systems often represent data using vectors, matrices, feature vectors, image matrices, and numerical transformations.

## Teaching Logic

```text
First:  Organize, document, and build projects (Phases 0–2).
Then:   Math intuition for AI features (this module).
Finally: Apply in design, coding, ML/CV, and capstone projects.
```
