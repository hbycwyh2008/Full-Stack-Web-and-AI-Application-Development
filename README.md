# Full-Stack Web & AI Application Development

**Design · Build · Test · Publish**

A browser-based, project-driven computer science course.

## Course Purpose

Students learn computer science by making real software for real users—moving from user needs to published interactive websites and browser games, while building AI literacy alongside the build process.

## The Learning Journey

```text
DISCOVER     →  user needs & HCI questions
DESIGN       →  Figma wireframes & interactive prototypes
BUILD        →  HTML · CSS · Bootstrap · JavaScript
COLLABORATE  →  GitHub workflow & peer review
TEST         →  HCI experiments, evidence & iteration
CREATE       →  interactive websites & browser games
```

## AI Literacy (parallel track)

Students read and discuss Melanie Mitchell's *Artificial Intelligence: A Guide for Thinking Humans*, and practice four core habits:

- understand what AI can and cannot do
- recognize hallucinations
- use AI responsibly
- disclose AI assistance

## Course Outcomes

By the end of the course, each student has:

| Outcome | Evidence |
|---|---|
| **Figma prototype** | Interactive wireframes / high-fidelity prototype |
| **Published web project** | Live interactive site or browser game |
| **GitHub portfolio** | Issues, branches, PRs, peer review, releases |
| **HCI evidence** | Research notes, usability tests, iteration log |

## Priority

### Primary
- Discover → Design → Build → Collaborate → Test → Create
- HCI research and evidence-based iteration
- Figma product design
- HTML / CSS / Bootstrap / JavaScript
- GitHub workflow and peer review
- AI literacy (Mitchell + responsible use)

### Optional if time remains
- Python foundations
- small AI-application / API extensions

React, Next.js, FastAPI, MongoDB, RAG, Kaggle, ML model training, and similar tools are enrichment, not core outcomes.

## Classroom Method

Every class is **45 minutes** and follows **Our Classroom Flow**:

```text
Skill Warm-up → Talk Robin 1 → Entry Check → Core Pattern
→ Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence
```

*We learn. Practice. Rebuild. Share.* The goal is not only to finish a task, but to **rebuild and explain it independently**.

See [02_Class_Missions/shared/classroom-flow-45-min.md](02_Class_Missions/shared/classroom-flow-45-min.md).

Steps 1–3 for Discover → Create use named resources; **AI Literacy** uses Melanie Mitchell’s *Artificial Intelligence: A Guide for Thinking Humans* only — see [09_Teacher_Planning/Daily_Lesson_Plans/shared/classroom-flow-steps-1-3-coursera.md](09_Teacher_Planning/Daily_Lesson_Plans/shared/classroom-flow-steps-1-3-coursera.md).
