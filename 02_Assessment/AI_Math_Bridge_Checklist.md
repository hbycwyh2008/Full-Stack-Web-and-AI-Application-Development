# AI Math Bridge Checklist

Use for **Phase 3** self-assessment or teacher sign-off. Prioritize **conceptual clarity and project connection** — not symbolic proofs.

## Conceptual Understanding

- [ ] Can explain a **vector as data** (e.g., student scores, features).
- [ ] Can explain a **matrix as a table or image** (rows/columns, pixels).
- [ ] Can identify **X matrix** and **y vector** in ML code (`model.fit(X, y)`).
- [ ] Can explain **dot product intuition** (similarity / alignment).
- [ ] Can explain **image as matrix** (grayscale 2D, RGB 3D).
- [ ] Can explain **eigenvector / PCA intuition** at a high level (important directions, compression).

## Practice Evidence

- [ ] Completed **NumPy mini lab** with shapes and basic operations.
- [ ] Completed **image matrix mini project** (load/inspect/modify/display).
- [ ] `ai-math-bridge/` folder on GitHub with required files.

## Explanation and Reflection

- [ ] README follows template and is in the student's own words.
- [ ] Can connect math ideas to **AI / ML / CV** (not just math class).
- [ ] `pca-reflection.md` or equivalent reflection submitted.

## Not Required

- Formal proofs or heavy symbolic algebra
- Full 3Blue1Brown playlist (unless advanced track)
- Full DeepLearning.AI linear algebra course
