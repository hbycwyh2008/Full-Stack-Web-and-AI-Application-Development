# Lesson 19 — Values, Variables, Conditions, and Functions

## Mission
Model a small product behavior as data and decisions before touching the DOM.

## Core Artifact
`script.js` containing tested functions for one product rule.

## Launch Challenge — 0–10
Given a behavior such as “show a different message based on form input,” students write **input, processing, output, edge cases** in plain language.

## Evidence / Resource Scan — 10–25
Use one short JavaScript reference covering values/types, `const`/`let`, comparisons, `if`, parameters, return values, and function calls.

## Team Sensemaking — 25–40
Teams predict outputs of short snippets before running them. Differences are resolved by executing and explaining the actual result.

## Studio Build — 40–65
Write small functions that implement a project rule. Each function must have clear inputs, return/output behavior, and at least three test cases including an edge case.

## Critique / Test — 65–80
Partners receive only the function contract and test it with new inputs. Any surprising behavior becomes a bug report.

## Ship Evidence — 80–90
Fix one issue and commit the tested function.

## Success Evidence
Students can explain data flow through a function and distinguish a condition from an action.
