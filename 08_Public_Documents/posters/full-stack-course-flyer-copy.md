## English Version

### Full-Stack Web Development

**AI-Enhanced Development | Project-Based Learning | Future-Ready Skills**

Students learn to design and build real websites and web applications from the front end to the back end. They also learn to use AI responsibly for coding assistance, debugging, problem solving, and creative development.

### Students will learn

- HTML, CSS, and JavaScript fundamentals
- Front-end and back-end development
- Databases, APIs, and user login systems
- GitHub collaboration and project deployment
- Using AI for coding assistance, debugging, and code improvement
- The full development process from idea to finished product

### AI Is Embedded Throughout the Course

Students do more than ask AI to generate code. They learn how to:

- describe requirements and problems clearly to AI tools;
- evaluate whether AI-generated code is correct;
- debug and modify AI suggestions;
- explain the code they ultimately submit;
- use AI to improve productivity without replacing understanding.

### Skills Developed

- Computational thinking
- Problem solving
- Digital creativity
- Collaboration and communication
- AI literacy

### Why This Course Matters

- **Build real products:** Students create working projects they can demonstrate and be proud of.
- **Move from user to creator:** Students use code to turn ideas into useful digital products.
- **Prepare for future learning and careers:** Students build foundations for modern web development, software engineering, and AI applications.
