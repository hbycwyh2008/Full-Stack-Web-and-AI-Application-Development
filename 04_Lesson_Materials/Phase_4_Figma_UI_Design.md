# Phase 4: Figma UI Design

## Phase Goal
Design the app interface in **Figma after AI Math Bridge** and **before TypeScript / Next.js** — plan layout, navigation, and key screens.

## Key Concepts
- Frame, wireframe, components, navigation.
- Design first, then code (Phases 5–6).
- Show answer **source** on mockup (connects to literacy + RAG).

## Required Student Output
- Figma mockup: home, main feature, form, result page, navigation.
- `design/figma-link.md` in GitHub.

---

## Suggested Lesson Count
2 lessons.

## Lesson Sequence

### Lesson 1: Wireframes and Layout
- **Goal:** Sketch AI School Assistant flow (question → answer → source).
- **Warm-up:** Map user flow on paper.
- **Mini Lesson:** Frames, wireframes; align with teacher demo UX.
- **Guided Practice:** Class wireframe in Figma.
- **Independent Work:** Home + main feature screens.
- **Exit Ticket:** Main user action on your app?
- **Homework:** Form + result wireframes.

### Lesson 2: Components and Handoff
- **Goal:** Reusable components; link in repo.
- **Guided Practice:** Navbar + question card components.
- **Independent Work:** Polish screens; `design/figma-link.md`.
- **Exit Ticket:** First screen to build in Next.js (Phase 6)?
- **Homework:** Review mockup before Phase 5 TypeScript intro.

## Submission Requirements
- [ ] Figma link with 3–4 screens.
- [ ] Source display planned on result screen.
- [ ] Link in GitHub.
