# Lesson 11 — Figma Frames, Auto Layout, and Components

## Mission
Build a reusable design system instead of manually duplicating disconnected screens.

## Core Artifact
A Figma file containing frames, styles/variables as appropriate, auto layout, and reusable components.

## Launch Challenge — 0–10
Inspect a duplicated mockup and identify what will become inconsistent if every button/card is edited separately.

## Evidence / Resource Scan — 10–25
Use one short Figma reference/demo covering frames, constraints, auto layout, and components. Students record what problem each feature solves.

## Team Sensemaking — 25–40
Teams choose which repeated interface elements should become components and which values should be consistent across screens.

## Studio Build — 40–65
Create reusable button, navigation, input, card, and feedback components needed by the project. Apply auto layout and sensible naming. Build at least one mobile and one larger-screen frame.

## Critique / Test — 65–80
Partner changes a component property/content and checks whether the design adapts without breaking. Identify brittle layouts.

## Ship Evidence — 80–90
Fix layout/component issues and add a brief component inventory to the project documentation.

## Success Evidence
Students can explain why reusable components and layout rules make design changes safer and faster.
