# Teacher Start Here — Software Design, Development & AI

## Canonical Curriculum

Use [02_Class_Missions/README.md](02_Class_Missions/README.md). It contains the rebuilt **33-lesson core pathway**, six integrated AI literacy studios, and optional Python extension.

## Priority Order

1. complete software-development lifecycle;
2. GitHub development workflow;
3. HCI research end to end;
4. Figma design/prototyping end to end;
5. AI literacy through Melanie Mitchell;
6. HTML/CSS/JavaScript implementation fluency;
7. Python only if time remains.

React/Next/FastAPI/RAG/Kaggle/ML/Cursor/Notion materials elsewhere in the repository are legacy/enrichment unless deliberately selected for an extension. Do not let them replace the core outcomes.

## Classroom Flow

Use [activity/discussion studio flow](02_Class_Missions/shared/classroom-flow.md). Students first inspect/create evidence, discuss, build, critique/test, revise, and ship. Avoid leading the whole lesson through serial teacher questions.

## Assessment Lens

Assess the chain of evidence:

**research → requirement → design → issue/branch/PR → implementation → test → revision → release → retrospective**.

A technologically simple project with a strong evidence chain is stronger than a framework-heavy project with weak HCI/testing/process evidence.
