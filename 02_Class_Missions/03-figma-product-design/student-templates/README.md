## Submission rule

GitHub stores the **reasoning evidence**. Figma stores the actual prototype.

Each Markdown file should contain the current Figma URL and required screenshots.

## Evidence rule

A change counts as evidence-driven only when the student can point to:

1. a design-principle problem, or
2. something a tester actually did/said.

## Exit gate

L11 contains the **Design → Build Gate**. Do not implement a known-bad interaction simply because the prototype looks polished.
