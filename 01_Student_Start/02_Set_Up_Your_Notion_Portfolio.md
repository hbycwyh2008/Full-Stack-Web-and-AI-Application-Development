# Set Up Your Notion Portfolio

After the GitHub lessons in **01 GitHub Notion**, you create a **Notion portfolio** — a public site that showcases your best finished work.

---

## GitHub vs Notion

| | GitHub | Notion |
|---|---|---|
| **Purpose** | **Learning evidence** and process | Public **portfolio** |
| **Shows** | Commits, code, reflections, **revision record** | Polished projects and summaries |
| **Audience** | You, teacher, future reviewers of your process | Anyone — colleges, programs, employers |

Add your Notion link to your GitHub `README.md`.

---

## Step 1: Create a Notion Workspace

Use a school account or personal Notion account.

---

## Step 2: Use the Portfolio Template

Follow: [Student Portfolio Template](../03_Templates/Student_Portfolio_Template.md)

Include at minimum:

- About you
- Learning goals
- Project pages (add more in each numbered course unit)
- Links to your GitHub repo

---

## Step 3: Publish a Public Link

1. Share → Publish to web
2. Copy the public URL
3. Add it to your GitHub `README.md`
4. Commit: `Add Notion portfolio link to README`

---

## Step 4: Update Each Numbered Unit

When you finish a strong project:

1. Add or update a project page in Notion
2. Link to the GitHub folder for that project
3. Include a short summary — this is part of your **program report** for the public

Class missions: [01 GitHub Notion](../02_Class_Missions/01-github-notion/README.md)

---

## Evidence to Submit

- Notion public link in GitHub README
- Screenshot of portfolio homepage
- **Reflection** on why portfolio matters for your goals
