# 14 Final AI Web App Projects

Use this folder for final AI web app project build missions.

Students should combine:

1. Frontend
2. Backend
3. AI feature
4. Data or retrieval component
5. Evidence and reflection

The final product should be more than a demo. It should have a clear user, purpose, and explanation.
