# Role Card — Collaborator A / CSS

## Your Feature

```text
Branch: feature-css
Issue: Add page styling
Primary file: style.css
```

## Your Workflow

1. Accept the Owner's collaborator invitation.
2. Clone the **shared** `team-web-launch` repository locally.
3. Confirm the CSS Issue is assigned to your GitHub account.
4. Create `feature-css` locally.
5. Build substantive CSS in `style.css` without taking over `index.html` or `script.js`.
6. Stage and commit locally with a meaningful message.
7. Push `feature-css` into the shared repository.
8. Open `feature-css → main` as a Pull Request.
9. Include **What changed**, **Why**, **Testing**, and `Closes #<your actual CSS Issue number>`.
10. Wait for the Owner's review. Do not merge your own PR.
11. If the Owner requests changes, edit locally, commit, and push to the **same branch** so the existing PR updates.
12. After all team PRs are merged, complete **🔄 Local Sync Check** by pulling `main` and posting the required `SYNCED SHORT_SHA` proof.
13. Complete **🧠 Final Reflection** after it appears.

## Commit Rule

The checker expects local-style Git commit evidence. Do not complete the CSS feature only through GitHub's web editor.

Use a meaningful message such as:

```text
Add responsive page styling
```

not:

```text
update
final
fix
```
