# 08 — AI Literacy Reading and Discussion Thread

AI literacy is a **primary course strand**, but it is not taught as a detached sequence of AI demos. The spine is Melanie Mitchell's **_Artificial Intelligence: A Guide for Thinking Humans_**.

These are **20–30 minute reading/discussion studios** inserted through the software course. Page numbers can vary by edition, so the teacher assigns the relevant chapter/section from the book rather than copying book text into this repository.

## Discussion Routine

1. Read the assigned section and annotate **one claim, one example/evidence, one uncertainty**.
2. Each student speaks before open discussion begins.
3. Teams build a **claim–evidence–limitation** board.
4. Connect the reading to a software/product decision.
5. Commit a short reading note; do not submit chapter summaries copied from the book or AI.

## Course Standard

Students should become able to say not only **what an AI system can do**, but also **what evidence supports the claim, what the system may not understand, where it can fail, and what that means for product design**.
