## Classroom Flow Poster

**Message:** We learn. Practice. Rebuild. Share.

The poster shows the class learning cycle:

1. Skill Warm-up
2. Talk Robin 1
3. Entry Check
4. Core Pattern
5. Guided Practice
6. Independent Rebuild
7. Talk Robin 2 + Evidence

**In daily lesson plans and mission guides**, the 80-minute block uses **eight timed sections** (Entry Check before Talk Robin 1; Exit Evidence as its own final block). The poster and written guides teach the **same cycle** — see `07_Class_Mission_Guides/shared/classroom-flow.md`.

## Mastery Level Poster

**Message:** Not just working code. Real understanding.

- Running code once is only the start.
- Real mastery: explain, rebuild, debug, modify, apply.
- Evidence: certificates, code, reports, reflections, revisions.

Aligns with `shared/mastery-levels.md` (Levels 0–5) in mission guides and daily lesson plans.

## CS Competition Pathways Poster

Optional pathways for students who want challenges beyond the core course:

- Programming & computational thinking (BEBRAS, ACSL, USACO)
- Cybersecurity (picoCTF, CyberPatriot, CTF)
- AI & data science (IOAI, Kaggle, AI projects)
- Robotics & engineering (VEX, FIRST, computer vision)

Not required for course credit — supports portfolio and college applications.
