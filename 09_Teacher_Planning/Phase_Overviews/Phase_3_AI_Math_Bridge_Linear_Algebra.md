# Phase 3: AI Math Bridge — Linear Algebra for AI

**Your goal:** Build **visual, intuitive** linear algebra foundations connected to AI, ML, and computer vision — not a full proof-based math course.

**Lesson guides:** [05_Resources/AI_Math_Bridge/README.md](../../05_Resources/AI_Math_Bridge/README.md) · [AI_Math_Bridge_Overview](../../05_Resources/AI_Math_Bridge/AI_Math_Bridge_Overview.md)

---

## What You Will Learn

- Vectors and matrices as **data** (not abstract homework)
- Feature vectors, dot product, similarity intuition
- Images as matrices; basic NumPy
- How `X` and `y` connect to ML; PCA intuition (high level)

---

## Why This Matters

Later you will use **embeddings, retrieval, and RAG**. Math bridge helps you understand *why* similarity search works — connecting Phase 2 literacy to Phase 8 RAG and your final app.

## In-Class Learning Flow

### 1. Skill Warm-up
Watch selected **3Blue1Brown** clip or complete warm-up in lesson guide. Write: “A vector is ___ in data terms.”

### 2. Talk Robin Round 1
- **You:** “A vector could represent ___ in an AI app.”
- **Partner:** “A matrix could represent ___.”

### 3. Entry Check
1. What is a feature vector?
2. Where will Phase 3 evidence live?
3. How is a spreadsheet like a matrix?

### 4. Core Pattern
```text
watch intuition → write notes → lab (NumPy/image) → reflect → commit to ai-math-bridge/
```

### 5. Guided Practice
Follow daily lesson guide: notes files, NumPy mini lab, image-as-matrix activity per teacher schedule.

### 6. Independent Rebuild
- [ ] `vector-notes.md`, `matrix-notes.md`, `dot-product-notes.md`
- [ ] NumPy lab notebook or exported script
- [ ] Image matrix mini project or screenshot
- [ ] Meaningful commits

### 7. Talk Robin Round 2 + Evidence
Connect dot product to “finding similar text” preview for RAG. Submit phase evidence.
