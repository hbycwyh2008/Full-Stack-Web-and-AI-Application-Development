# Admin Curriculum Package

**Chongqing Norin Bashu School for Children of Foreign Personnel**  
**Computer Science and AI Pathway**

## Purpose

This folder is for **school leaders, parents, and curriculum reviewers**. It explains the pathway, scope, evidence model, and assessment philosophy **without** exposing full lesson scripts, answer keys, the complete project bank, or the full prompt library.
