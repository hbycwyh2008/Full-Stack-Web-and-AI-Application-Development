## Lesson Goal

After watching the official video, students can improve a professional GitHub profile without publishing private information and identify essential account protections.

This lesson uses **one video and one guided practice**. Do not re-teach the Classroom Flow posters and do not assign another playlist video as homework.

## 45-Minute Lesson Flow

| Time | Block |
|---|---|
| **0–10 min** | **Skill Warm-up** — watch this lesson's official video only; stop at 10 minutes if needed |

| **21–32 min** | **Guided Practice** — complete the named task with checkpoints |

### 0–10 min: Skill Warm-up

Watch **playlist #8 only**: [GitHub Profile Tips to standout (& stay secure)](https://www.youtube.com/watch?v=T_PKBNImooA).

While watching, record:

- One new term
- One action demonstrated
- One question to test during practice

### 10–13 min: Talk Robin 1

- **A:** “The video's main idea is…”
- **B:** “A step I need to remember is…”

### 13–17 min: Entry Check

1. What artifact did you create last lesson?
2. Where can you verify a change in GitHub?
3. What must never be copied into a public repository?

### 17–21 min: Core Pattern

Teacher demonstrates the task once and points out where students can verify the result. Students identify the action, the artifact, and the evidence before beginning.

### 21–32 min: Guided Practice

1. Review the public profile fields shown in the video and remove anything unsuitable for a public audience.
2. Add or improve one real profile element: bio, safe project link, or profile README.
3. Open account security settings and verify 2FA status. Enable it only with teacher/guardian-approved recovery-code storage.
4. Record only a yes/no safety checklist in `github-foundations/08-profile-security-audit.md` and commit it with `Add profile security audit`; never record recovery codes, passwords, phone numbers, or tokens.

### 32–40 min: Independent Rebuild

Inspect the public profile as a visitor would, then independently make one safe improvement without copying the teacher's wording. Verify a working evidence link and confirm privately that no school-private or recovery information is exposed.

### 40–45 min: Talk Robin 2 + Evidence

Name two pieces of safe public profile information and two items that must remain private.

Add to `learning-log.md`:

```markdown
## Lesson 8
- What I did:
- What I learned:
- What was hard:
- Evidence link:
```

Commit the learning-log update if the lesson's practice did not already require that exact commit. **Homework is only the unfinished Lesson 8 learning-log entry; no video homework.**

## Common Mistakes

- Watching or assigning a second playlist video
- Completing clicks without checking the resulting artifact
- Using vague commit messages such as `update`
- Publishing passwords, tokens, recovery codes, or other private information
- Treating a screenshot as a substitute for repository evidence
