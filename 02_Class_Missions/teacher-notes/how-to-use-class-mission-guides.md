# How to Use Class Mission Guides (Teacher)

## What These Are

`02_Class_Missions/` is the **student-facing execution layer**. Students open these files during class and follow step by step.

| Folder | Audience | Purpose |
|---|---|---|
| `09_Teacher_Planning/Phase_Overviews/` | Teachers | Phase overview |
| `09_Teacher_Planning/Daily_Lesson_Plans/` | Teachers | Session scripts, timing, cold-call notes |
| **`02_Class_Missions/`** | **Students** | **Today’s mission, rebuild, evidence** |

Mission guides are **not** a replacement for daily lesson plans. They are the document students see on their screens.

---

## How to Deploy in Class

1. **Before class:** Post link to today’s mission file (LMS, QR, or repo path).
2. **Entry Points Check:** Use group answers to choose what to explain in Teacher Explanation / Core Pattern (42–55 min).
3. **Independent Rebuild:** Students follow checklist in mission guide — you circulate.
4. **Talk Robin 2 + Evidence:** Students submit what “What You Must Submit” lists (83–90 min).

Student-facing flow and timing: `../shared/classroom-flow.md` (**90 minutes**).

---

## Writing Style Difference

Mission guides use **“you”** — no “the teacher will…” in student files.

Teacher strategy lives in `09_Teacher_Planning/Daily_Lesson_Plans/teacher-notes/`.
