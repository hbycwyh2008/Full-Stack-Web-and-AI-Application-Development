# AI Studio C — Vision and Deep Learning

**Book spine:** assigned sections on computer vision / deep learning.

## Activity
Students compare human descriptions of an image with labels/features a vision system might use. Teams identify which aspects are pixels/patterns and which require context or background knowledge.

## Discussion
A system can classify an image accurately. What does that evidence prove, and what does it not prove about understanding?

## Product Connection
Sketch a user flow containing a hypothetical vision feature. Add at least two failure/recovery states and a human override or feedback path where appropriate.

## Evidence
Commit one capability claim, one failure mode, and one design implication.
