## Mission Goal

Today you will learn **how this course works by doing the classroom process**, not by listening to a syllabus lecture.

By the end of class, you should be able to explain:

- what you will eventually build in this course;
- how this class moves from individual learning to discussion, practice, and evidence;
- why working code once is not the same as mastery;
- how AI can support learning without replacing your thinking;
- what is expected from your grade band.

---

| Time | Block | What you do today |

## 0–10 min — Entry Point Check

**Work individually. Do not discuss yet.**

### Quick Sort

For each statement, mark **Agree / Disagree / Unsure**.

| Statement | Agree | Disagree | Unsure |
|---|:---:|:---:|:---:|
| If my code runs once, I have mastered it. |  |  |  |
| Using AI to explain an error can support learning. |  |  |  |
| Following a tutorial exactly is the same as rebuilding independently. |  |  |  |
| A full-stack AI application connects more than one system or layer. |  |  |  |
| Competitions are required in this course. |  |  |  |

Then write one sentence:

> **The statement I am least sure about is __________ because __________.**

Keep this page. You will revisit your choices later.

## 25–40 min — Talk Round 1: Compare and Build

Work with one partner.

### Round A — 60-Second Share

Student A speaks for up to 60 seconds:

- one poster idea that changed or confirmed their thinking;
- one piece of evidence from the poster.

Student B listens and records **one idea they did not write themselves**.

Switch roles.

### Round B — Find One Agreement and One Disagreement

Together, write:

- **We agree that:** ________________________________________________
- **We disagree / are unsure about:** _________________________________

### Round C — Build a Two-Sentence Explanation

Without copying the poster text, create a two-sentence explanation of how learning works in this course.

> **Sentence 1:** In this course, learning means ______________________________.
>
> **Sentence 2:** Evidence of mastery is stronger when ________________________.

Be ready to carry these ideas into your group board. You are not preparing to answer teacher questions; you are preparing to compare evidence with another group.

---

## 40–55 min — Entry Points Check / Teacher Diagnosis: Group Claim Board

Join a group of 3–4.

Create **one shared board or sheet** with four boxes.

### Box 1 — Classroom Flow

Arrange these ideas in the order that best represents the course learning cycle:

`learn` · `practice` · `rebuild` · `share`

Under the sequence, add:

> **Rebuild matters because:** ______________________________________________.

### Box 2 — Mastery

Place each example under **Weak Evidence** or **Strong Evidence**.

- copied working code;
- can explain the logic;
- can rebuild the pattern without the full solution;
- can debug a changed version;
- watched the whole tutorial;
- can apply the pattern in a new situation.

### Box 3 — AI Use

Sort each scenario into **Supports Learning / Replaces Thinking / Needs More Context**.

- AI explains an error message, then you fix the code yourself.
- AI generates the entire assignment and you submit it unchanged.
- AI suggests two approaches; you test both and explain your choice.
- AI writes code that works, but you cannot explain it.
- You use AI and document how it helped.

### Box 4 — Unresolved Point

Write exactly **one disagreement or uncertainty** your group could not settle.

During the diagnosis portion, compare your board with another group's board. Use the short class clarification only for patterns the groups could not resolve from the posters themselves.

### Group Evidence

Before moving on, every group member must be able to point to one decision on the board and explain the evidence behind it.

Complete both activities with your group.

### Activity A — Scenario Challenge

For each scenario, decide:

1. **What course principle applies?**
2. **What should the student do next?**
3. **Which poster supports your decision?**

## 75–85 min — Exit Check: Individual Transfer

Return to your original **Quick Sort** from the first 10 minutes.

### Step 1 — Recheck

Change any answer you would now mark differently. Circle one changed answer.

### Step 2 — Explain the Change

> At first I thought ____________________. Now I think ____________________ because ____________________.

### Step 3 — New Situation

Read this new scenario:

> You completed a class task successfully with notes and examples open. The next day, the examples are closed and one part of the task has changed.

Write what you should do to show real learning:

> ____________________________________________________________________

### Step 4 — Course Destination

Look at this simplified destination:

```text
   ↓

   ↓
working full-stack AI application
```

Write:

- **One layer I recognize:** __________________________
- **One layer that is new to me:** ____________________
- **One thing I want to learn how to connect:** _______

## 85–90 min — Submission

## What You Must Submit

Submit **your own individual evidence**, plus your group's shared board if requested.

### Individual Evidence

1. completed Entry Point Quick Sort;
2. four-poster evidence table;
3. partner agreement/disagreement notes;
4. completed Individual Transfer exit check;
5. one grade-band success sentence.

### Group Evidence

- one Group Claim Board with all four boxes completed.

---

## Success Criteria

You are ready for the next lesson when you can show, through your activity evidence, that you understand:

- the course learning cycle;
- why rebuild and explanation matter;
- the difference between AI support and AI replacement;
- that competitions are optional enrichment;
- the broad course pathway;
- what success looks like for your grade band.

### Middle School Requirement

You can **identify, sort, and explain** the major course expectations in your own words.

### High School Requirement

You can **justify, transfer, and apply** the course expectations to a new situation without relying on the poster wording.

---

## Remember

> **You learn the course culture by doing it: observe → discuss → decide → apply → submit evidence.**

> **Middle School:** Build, modify, and explain.  
> **High School:** Rebuild, debug, integrate, and transfer.

> **AI supports learning. It does not replace thinking.**
