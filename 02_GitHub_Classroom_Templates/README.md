# GitHub Classroom Assignment Templates

> These templates are designed to be **copied into organization-owned GitHub Classroom template repositories**. The private master repository should **not** be directly used as a GitHub Classroom template.

> GitHub Classroom template repositories should contain **only the files students need for that specific assignment**.

## Each Template Includes

```text
README.md                 ← assignment instructions (student-facing)
starter_files/            ← sanitized starter code (add from 07_Starter_Code_Master/)
submission_checklist.md   ← student checklist
reflection.md             ← reflection scaffold
```

---

## What NOT to Include in Classroom Templates

- Complete solution code
- Teacher explanation scripts
- Private Cursor / teacher prompts
- Full grading rubrics with teacher notes
- Internal planning comments

---

## Workflow

1. Choose a template folder from this directory.
2. Copy **only** `README.md`, `starter_files/`, `submission_checklist.md`, and `reflection.md` into a new **template repository** in your GitHub Organization.
3. Mark the repo as a **GitHub Classroom template**.
4. Create a Classroom assignment from that template.
5. Students receive their own copy — never the master curriculum repo.
