# Daily Lesson Plans

**Course:** Full-Stack Web and AI Application Development

Ready-to-teach **session-by-session** lesson plans following the classroom poster model.

The course now begins with a dedicated **Day 1 Course Orientation** before GitHub setup or coding begins.

## Day 1 — Course Orientation

**Teacher lesson:** [Phase_00_Course_Overview/lesson-00-course-orientation-poster-quest.md](Phase_00_Course_Overview/lesson-00-course-orientation-poster-quest.md)
**Student mission:** [required-orientation-four-posters.md](../../02_Class_Missions/00-course-orientation/required-orientation-four-posters.md)

**Duration:** 45 minutes

Day 1 focuses on:

- course destination and final-project preview;
- Poster Quest using the four official course posters;
- classroom flow and mastery expectations;
- responsible AI use;
- optional competition pathways;
- the 00–15 learning pathway;
- Middle School vs High School expectations.

**Do not turn Day 1 into a syllabus lecture.** Students should discover and explain the course expectations through the posters, discussion, and exit evidence.

---

## Standard Daily Flow

Most technical daily plans follow the classroom learning model:

```text
Skill Warm-up → Entry Check → Talk Robin 1 → Teacher Pattern → Guided Practice
→ Independent Rebuild → Talk Robin 2 → Exit Evidence
```

**80-minute technical-lesson default timing:** 0–20 / 20–30 / 30–34 / 34–45 / 45–60 / 60–72 / 72–76 / 76–80

The Day 1 orientation uses a dedicated **90-minute** structure because it includes the Poster Quest and grade-band orientation.

**Course posters:** [08_Public_Documents/posters/](../../08_Public_Documents/posters/README.md) — classroom flow, mastery level, AI use policy, CS competition pathways.

## Grade-Band Differentiation

Both classes use the same repository and learning pathway.

- **Middle School:** Build · Modify · Explain
- **High School:** Rebuild · Debug · Integrate · Transfer

See: [Grade-Band Expectations](../../00_Course_Overview/Grade_Band_Expectations.md).

When a mission needs different expectations, keep one mission and include separate **Middle School Requirement** and **High School Requirement** sections.

## Course Principles (All Lessons)

- Not lecture-only; watching ≠ mastery; copying ≠ mastery
- Rebuild, debug, explain, submit evidence
- AI supports learning — does not replace thinking
- Oral explanation may be required
- Most learning in class; light homework if evidence is unfinished

See `shared/classroom-learning-workflow.md` and `04_Assessment/Student_Learning_Expectations.md`.
