# Phase 6: Next.js Frontend

**Your goal:** Build the **Next.js + TypeScript** user interface from your **Figma mockup** (Phase 4) using types from Phase 5.

---

## What You Will Learn

- React components, props, App Router, layouts, forms
- Typed components with `.tsx`
- Frontend role: UI only — **FastAPI is the backend** (Phase 7), not Next.js API routes for core logic

---

## Why This Matters

This is the face of your AI School Assistant. You prove you can **rebuild** UI from design, not only copy tutorials — with evidence in GitHub commits and README.
