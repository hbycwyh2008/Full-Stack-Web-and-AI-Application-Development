## What You Will Be Able to Do After This Sequence

- Explain what GitHub is for in this course
- Create and organize your `[studentName]-Full-Stack-Web-and-AI-Application` repo
- Write README and Markdown notes
- Make **meaningful commits** and read **commit history**
- Explain saving vs committing vs pushing
- Submit evidence every class
- Explain your work orally when asked

**Not in this first GitHub sequence:** rebase and advanced collaboration workflows.
