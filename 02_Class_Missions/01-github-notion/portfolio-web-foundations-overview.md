# Portfolio Web Foundations — Class Missions

**Goal:** Build one portfolio pathway from no-code publishing to real frontend development.

This folder combines four connected learning blocks:

1. **Notion Portfolio** — publish a no-code portfolio site
2. **HTML/CSS** — build a digital business card
3. **JavaScript** — add interaction and logic
4. **React** — rebuild the portfolio as reusable components

Students should keep using the same GitHub repository:

```text
[studentName]-Full-Stack-Web-and-AI-Application
```

Notion is the public showcase. GitHub is the evidence and revision history.

---

## Course Sequence

| Block | File | Suggested time | Main evidence |
|---|---|---:|---|
| 1 | [module-01-notion-portfolio.md](module-01-notion-portfolio.md) | 2 classes | Published Notion portfolio |
| 2 | [module-02-html-css-digital-business-card.md](../03-html-css-basics/module-02-html-css-digital-business-card.md) | 6 classes | HTML/CSS digital business card |
| 3 | [module-03-javascript-interactive-profile.md](../04-javascript-basics/module-03-javascript-interactive-profile.md) | 8–10 classes | Interactive profile page |
| 4 | [module-04-react-component-portfolio.md](../05-react-basics/module-04-react-component-portfolio.md) | 8–10 classes | Component-based React portfolio |

Each class is assumed to be **90 minutes**.

Fast track total: about **16 classes**.
Recommended total: about **24–28 classes**.
Zero-background total: about **32 classes**.

## Classroom Learning Cycle

Each class should still follow the same classroom model:

```text
individual learning → Talk Robin / group discussion → group answer → Entry Points Check → teacher explains only what students do not understand → mission task → exit check → submission of evidence
```

Do not make these blocks teacher-demo-first. Students should watch, practice, discuss, rebuild, explain, and submit evidence.

---

## Final Outcome

By the end of this folder, students should have:

1. A published Notion portfolio
2. A GitHub repository with frontend project evidence
3. A digital business card made with HTML/CSS
4. A JavaScript-enhanced profile page
5. A React portfolio built from components
6. Links between Notion and GitHub
7. Reflections explaining what changed from no-code to code-based portfolio building

---

## Teacher Pacing Note

If the course schedule is short, keep the required product simple:

```text
Notion portfolio → HTML/CSS card → JavaScript interaction → React component rebuild
```

Do not add extra frameworks before students can explain HTML structure, CSS styling, JavaScript behavior, and React components in their own words.
