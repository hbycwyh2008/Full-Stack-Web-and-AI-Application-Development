# Lesson 7: X Matrix and y Vector in ML

## Goal

Understand the meaning of:

```python
model.fit(X, y)
```

## Key Ideas

- `X` = feature matrix (all samples, all features).
- `y` = target vector (labels or values to predict).
- Classification: `y` might be spam/not-spam, pass/fail, etc.

## Activities

1. Label `X` and `y` on a tiny Titanic-style table.
2. Screenshot or pseudocode explaining `fit()` in your README.
