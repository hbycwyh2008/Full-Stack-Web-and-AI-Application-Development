# Lesson 3: Feature Vectors in Machine Learning

## Goal

Connect one data point → **feature vector**; full dataset → **feature matrix**.

## Key Ideas

- Each row (or sample) in ML is often a feature vector.
- All samples together form the feature matrix `X`.

## Example

One Titanic passenger:

```text
[age, fare, sex_encoded, pclass]
```

Full Titanic dataset → matrix `X` with many rows.
