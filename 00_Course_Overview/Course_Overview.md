# Course Overview — Software Design, Development & AI

Current implementation: [Current Teaching Plan](Current_Teaching_Plan.md).

## Big Goal

Students learn **what computer science studies** and **how software is made responsibly and systematically**.

Computer science is broader than coding. It includes the study of computation, information and representation, algorithms, abstraction, computer systems and networks, human-computer interaction, artificial intelligence, security, software engineering, and the effects of computing on people and society.

Programming is important because it lets us express computational ideas and build systems, but programming is not the whole discipline.

## Core Competencies

### Computer Science Identity
Students can distinguish computer science from computer use, computer repair, and programming alone. They can connect course experiences to larger CS areas.

### Software Development
Students perform discovery, research, requirements, design, planning, implementation, review, testing, deployment, maintenance, and iteration.

### GitHub
Students use issues, branches, meaningful commits, pull requests, review, merge, and releases as normal development practice.

### HCI
Aligned to the CS6750 design life cycle. Students practice needfinding, ask/observe, survey craft, and evidence synthesis, but now explicitly check confirmation, leading, recall, observer, and sampling bias before turning data into 2–3 micro need/requirement statements. Full requirements documents remain deferred to Capstone.

### Figma
Students create three fast paper alternatives, choose one direction, build a 3–5 screen low-fi Figma wireframe, evaluate it with the course Core 3 (affordance/signifier, mapping, constraints) plus a real usability task, revise, then build a clickable high-fidelity prototype and retest. Selected Dan Scott Coursera lessons supply Figma tool instruction; CS6750 remains the theory backbone, with NN/g support for the two evaluation methods. Students complete separate tool knowledge/practical checks and evaluate Morgan's Skill Board before applying the methods to their own work.

### Programming
Students learn HTML, CSS, and JavaScript through Scrimba courses on Coursera, then apply those foundations in the Coursera Build Websites with Figma, HTML, and CSS course. They translate an existing Figma design into a responsive web page and add basic interactions. The required programming scope stays with web foundations and browser interaction; advanced frameworks and backend stacks are excluded from this stage.

### AI Literacy
Students complete the eight-meeting book seminar within lesson anchors 21–24, using group reading, student PPT presentations, evidence-based discussion, and a final integrated class synthesis deck based on Melanie Mitchell's _Artificial Intelligence: A Guide for Thinking Humans_. Contemporary prompting practice is clearly labeled as a supplement. AI implementation is not required in the web project.

### Python
Optional extension only when core outcomes are complete.

## AP CSP Foundation

The course can support later AP CSP study, but the AP CSP relationship is
documented separately and is **not repeated in Lesson 00**. Lesson 00 focuses
on what computer science is, how it differs from programming, and how
computational thinking supports problem solving through decomposition, pattern
recognition, abstraction, algorithm design, testing, and refinement.

## Teaching Principle

Students learn through artifacts and discussion: **inspect → compare → decide → build → critique/test → revise → preserve evidence**. Activity format changes with the content.

## Capstone

A released user-centered software product with complete lifecycle evidence. AI is optional.
