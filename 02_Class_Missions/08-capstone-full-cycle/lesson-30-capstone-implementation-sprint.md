# Lesson 30 — Capstone: Implementation Sprint

**Mission:** Implement the approved MVP through real GitHub workflow.

## Sprint Plan (0–10)

Select backlog issues for this sprint. Confirm owner, branch, acceptance criteria, and dependency order.

## Build (10–62)

Implement with HTML/CSS/JavaScript. Use feature/fix branches, meaningful commits, and small enough changes for review.

Teacher support is just-in-time. Students should use documentation, dev tools, prior lessons, and evidence before requesting code replacement.

## Integration Check (62–72)

Combine or preview branches and identify integration conflicts, visual inconsistencies, or shared-state assumptions.

## PR Review (72–85)

Review correctness, readability, duplication, semantic/accessibility quality, requirement coverage, and consistency with Figma. Authors revise before merge.

## Sprint Close (85–90)

Update backlog and record blocked work/risks.

## Deliverable

Reviewed implementation PRs + updated backlog.
