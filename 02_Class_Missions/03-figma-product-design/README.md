## Classroom flow

Same seven poster blocks as every class:

```text
Skill Warm-up → Talk Robin 1 → Entry Check → Core Pattern
→ Guided Practice → Independent Rebuild → Talk Robin 2 + Evidence
```

## Skill Warm-up source rule

1. **Primary:** OMSCS CS6750 Unit X.Y video from EdStem/Canvas (stop by 8:00).
2. **Backup:** Coursera Minnesota/Meta clip listed in the lesson — only if OMSCS access fails.

## Core outputs

brainstorm board + chosen direction → **3 low-fi prototypes** → peer-eval notes + new needfinding questions → clickable high-fi prototype + second eval / revision log.

## Standard

Teams must show more than one alternative before polishing a single screen. Evaluation uses user tasks, selected heuristics, and evidence — not “I like the color.”
