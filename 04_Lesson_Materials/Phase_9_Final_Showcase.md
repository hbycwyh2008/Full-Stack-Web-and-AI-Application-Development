# Phase 9: Final Showcase

## Phase Goal
Prepare and present the completed AI School Assistant, with full documentation and a clear demo.

## Key Concepts
- Putting all phases together into one working product.
- Presenting technical work clearly and answering questions.
- Demonstrating responsible AI use end to end.

## Required Student Output
- A working AI School Assistant (frontend + backend + documents + AI).
- A complete GitHub README and a Notion portfolio project page.
- A completed Responsible AI Checklist and AI usage reflection.
- A live or recorded demo.

---

## Suggested Lesson Count
2 lessons.

## Lesson Sequence

### Lesson 1: Prepare and Rehearse
- **Goal:** Finalize documentation and rehearse the demo.
- **Warm-up:** "What is the one thing you most want people to notice about your project?"
- **Mini Lesson:** What a strong demo looks like: clear purpose, smooth flow, honest explanation of architecture, data flow, and AI usage.
- **Guided Practice (Presentation Rehearsal):** In small groups, each student gives a 3-minute demo and gets timed feedback using the Presentation Rubric.
- **Independent Work:** Review the GitHub README, Notion portfolio page, Responsible AI Checklist, and AI usage reflection.
- **Exit Ticket:** List two questions you expect to be asked, and your answers.
- **Homework:** Fix any gaps found during rehearsal.

### Lesson 2: Final Showcase
- **Goal:** Present the AI School Assistant and submit the final package.
- **Warm-up:** Quick setup check — does the demo run?
- **Mini Lesson:** Reminder of expectations and respectful audience feedback.
- **Guided Practice (Showcase):** Students present their demos and answer Q&A.
- **Independent Work:** Submit the final package using the submission checklist below.
- **Exit Ticket:** One sentence — what are you most proud of, and what would you improve next?
- **Homework:** None — course complete.

## Submission Requirements (Final Submission Checklist)
- [ ] Working AI School Assistant demo (live or recorded).
- [ ] GitHub repo with a complete README (architecture + data flow).
- [ ] Notion portfolio project page.
- [ ] Completed Responsible AI Checklist.
- [ ] AI usage reflection.
- [ ] Project submission form (`01_Student_Templates/Project_Submission_Template.md`).

## Common Student Problems
- Demo breaks live → require a recorded backup and a setup check.
- Cannot explain their own architecture → rehearse the data-flow explanation.
- Weak AI disclosure → reinforce honest, specific reflection.
- Incomplete README or portfolio page → use the checklist before presenting.

## Teacher Notes
> 展示环节证明课程主旨：学生不仅会用 AI，更理解并负责任地用 AI 构建软件。The showcase proves the course thesis: students don't just use AI — they understand it and build with it responsibly. Use the Assessment Rubric and Presentation Rubric to grade.

## AI Lens Reflection
Ask students: *"Across the whole project, what did you build yourself, what did AI help with, and how did you stay responsible for the result?"* Save the answer in the portfolio as a final reflection.
