# Lesson 08 — Brainstorm Alternatives (Flow + Ideas)

**Length:** 45 minutes  
**Loop step:** Brainstorm Alternatives  
**Mission:** Turn needfinding evidence into several possible directions and a simple user flow — without polishing UI yet.  
**One Required Resource / Evidence Source:** team needfinding sheet + survey/ask/observe notes from HCI 05–07  
**Durable Evidence:** brainstorm board (8+ ideas) + one primary user flow sketch

## 0–5 min — Skill Warm-up

Review the team’s user evidence. List:

- one strong need backed by evidence;
- one idea that is only a guess;
- one task the user must complete.

Optional Coursera clip: Minnesota/Meta intro on flows or prototyping purpose (≤ 5–8 min). Write `I saw ___` / `I’m unsure about ___`.

## 5–9 min — Talk Robin 1

Pairs share evidence-backed needs vs feature guesses. Together pick **one** user goal for today’s brainstorm.

## 9–14 min — Entry Check

Individually write **four different** ways a student might reach that goal (not four colors of the same screen). Star the wildest idea and the safest idea.

## 14–19 min — Core Pattern

Teacher must-know:

**Brainstorm first, polish later.** Quantity before beauty. Alternatives beat one “perfect” sketch.

Groups run a timed brainstorm:

1. Silent sticky notes — 3 minutes (one idea per note)  
2. Share and cluster — 2 minutes  

Display: **8+ ideas** and one cluster labeled “backed by our needfinding.”

## 19–30 min — Guided Practice

Teams choose **3 promising directions** (not final UI). For the top direction, sketch a **primary user flow**:

- start;
- 3–5 steps;
- success;
- one place the user might get stuck.

Keep drawings gray-box only. Link each flow step back to a need or note from HCI when possible.

## 30–40 min — Independent Rebuild

Individually add one alternative path or recovery step the group missed. Explain how it helps the user need.

## 40–45 min — Talk Robin 2 + Evidence

Submit brainstorm board photo/link + flow sketch. State which **3 directions** will become low-fi prototypes in Lesson 09.

## Success Evidence

Students generate multiple alternatives from needfinding evidence and produce a simple user flow before styling.
