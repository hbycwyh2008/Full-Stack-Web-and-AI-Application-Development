# Lesson 6: GitHub Mastery Check

**Phase:** 0 — Git & GitHub  
**Duration:** 80 minutes  
**Student repo:** `cs-learning-log`

---

## Lesson Goal

Students **prove** GitHub mastery through independent written answers, meaningful commit, Exit Evidence, and oral explanation. Assign mastery level **3 minimum**; **4–5** for strong performance.

## Mastery Target

| Outcome | Level |
|---|---|
| Unit minimum | Level 3 — complete with checklist/rubric |
| Strong | Level 4 — without full instructions |
| Exceptional | Level 5 — explain, debug, help peer |

---

## Independent Task File

Create:

```text
mastery-check/final-github-practice.md
```

Answer in **student’s own words** (use examples from **your** `cs-learning-log`):

1. What is a repository?
2. What is a commit?
3. What is commit history?
4. What is the difference between saving, committing, and pushing?
5. Why is GitHub evidence important in this course?

**Commit** with meaningful message, e.g. `Add final GitHub mastery practice answers`.

---

## 80-Minute Lesson Flow

| Time | Block |
|---|---|
| 0–20 min | Skill Warm-up |
| 20–30 min | Entry Check |
| 30–34 min | Talk Robin Round 1 |
| 34–45 min | Teacher Pattern Explanation |
| 45–60 min | Guided Practice |
| 60–72 min | Independent Rebuild |
| 72–76 min | Talk Robin Round 2 |
| 76–80 min | Exit Evidence |

---

### 0–20 min: Skill Warm-up

**Unit pattern review** on paper (no devices):

1. Lesson 1 pattern
2. Lesson 2 pattern
3. Lesson 3 pattern
4. Lesson 5 commands (or web equivalent)

Pair check answers — no copying.

---

### 20–30 min: Entry Check

Without notes, write short answers:

1. What is a repository?
2. What is a commit?
3. What is commit history?
4. Saving vs committing vs pushing?
5. Why GitHub evidence in this course?

**Self-score:** How many without guessing? (0–5)

---

### 30–34 min: Talk Robin Round 1

- **A:** Answer #2 (commit) with example from **your** repo
- **B:** Answer #4 (save/commit/push) with example
- **Shared:** Which question is hardest?

---

### 34–45 min: Teacher Pattern Explanation

**Mastery check rules:**

- File path: `mastery-check/final-github-practice.md`
- All five questions — own words + personal repo examples
- Meaningful commit required
- Oral defense: 2–3 cold-call questions
- AI generic text → student must revise and explain orally

**Level assignment guide:**

| Level | How demonstrated |
|---|---|
| 3 | Completes with checklist / rubric visible |
| 4 | Completes without step-by-step handout |
| 5 | Oral excellence + helps peer locate history/commit issue |

**Oral sample questions:**

- “Show your last commit — what changed?”
- “Why is `update` weak?”
- “Saved locally but GitHub old — what do you check?”

---

### 45–60 min: Guided Practice

- Create `mastery-check/` folder
- Draft answers — teacher checks for personal examples (“In my `cs-learning-log` I have X commits…”)
- No copying from internet or AI without revision

---

### 60–72 min: Independent Rebuild

**Checklist:**

- [ ] `mastery-check/final-github-practice.md` complete (all 5)
- [ ] Personal repo examples included
- [ ] Meaningful commit pushed or committed on web
- [ ] Oral 30-second answers prepared
- [ ] Self-assessment sentence drafted

**Level 4:** close rubric after reading questions once.  
**Level 5:** after finishing, hint-only help for assigned peer on Commits tab.

---

### 72–76 min: Talk Robin Round 2

Practice oral — 45 sec each:

- **A:** Question 3 (commit history)
- **B:** Question 5 (why evidence matters)
- **Shared:** “My current level is ___ because ___.”

---

### 76–80 min: Exit Evidence

1. Link to `mastery-check/final-github-practice.md`
2. Screenshot of **final commit** on Commits tab
3. One sentence: **“My current GitHub mastery level is Level ___ because…”**
4. Oral cold call (2–3 students)

Use `shared/exit-evidence-checklist.md` Lesson 6 section.

## Common Mistakes

- Copied definitions — no personal example
- File only in root (accept if clear; prefer `mastery-check/`)
- Commit: `done` or `final`
- Cannot explain orally when called
