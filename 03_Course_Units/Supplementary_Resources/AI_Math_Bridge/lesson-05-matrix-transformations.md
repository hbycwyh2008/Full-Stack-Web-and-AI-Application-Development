# Lesson 5: Matrix Multiplication as Transformation

## Goal

See matrices as **transformations** of vectors and space (visual).

## Key Ideas

- A matrix can transform a vector.
- Linear transformations can rotate, stretch, or shear space.
- Images and shapes can be transformed with matrix operations.

## Activities

1. Watch selected **3Blue1Brown** videos (matrices as transformations, matrix multiplication).
2. Sketch before/after of one transformation in notes.
3. Class discussion: what changed on the grid?
