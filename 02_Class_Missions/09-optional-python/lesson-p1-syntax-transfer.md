# Optional Python P1 — Syntax Transfer from JavaScript

**Length:** 45 minutes  
**Mission:** Transfer programming concepts already learned in JavaScript into Python syntax without relearning programming from zero.  
**One Required Resource / Evidence Source:** teacher-provided JavaScript/Python comparison sheet  
**Durable Evidence:** translation exercises + small Python program

## 0–5 min — Skill Warm-up

Inspect paired JavaScript/Python examples. Record syntax differences for values, variables, `if`, loops, functions, lists, dictionaries, indentation, and printing.

## 5–9 min — Talk Robin 1

Pairs translate two tiny JavaScript snippets into Python on paper before running them. Compare translations and explain one syntax difference that does **not** change the underlying computational idea.

## 9–14 min — Entry Check

Individually predict which parts of a short JavaScript program represent concepts that should also exist in Python: variables, conditionals, loops, functions, arrays/lists, objects/dictionaries.

## 14–19 min — Core Pattern

Groups debug a short Python translation containing indentation, colon, type, or loop mistakes. Teacher clarifies only shared syntax-transfer barriers.

## 19–30 min — Guided Practice

Rebuild one previously understood JavaScript logic task in Python using variables, selection/iteration, and at least one function. Test with several inputs.

## 30–40 min — Independent Rebuild

Individually explain one concept that transferred directly from JavaScript and one Python syntax rule that required adjustment.

## 40–45 min — Talk Robin 2 + Evidence

Submit Python file, comparison notes, tests, and exit response.

## Success Evidence

Students recognize that core programming ideas transfer across languages and can adapt familiar logic into basic Python syntax.
