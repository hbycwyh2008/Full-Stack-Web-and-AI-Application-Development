# Student Portfolio Template

Copy this structure into your Notion portfolio. Replace the placeholder text with your own content.

---

## Home

- Your name
- One short sentence about who you are and what you build.
- A featured project or two.

---

## About Me

- A short bio.
- Your interests in CS / AI.
- What you are currently learning.

---

## Projects

For each project, create a page with:

- Project title
- Problem / purpose
- Tools used
- Main features
- Screenshots
- GitHub link
- What I learned
- What AI helped with
- What I changed myself
- Reflection

---

## Skills

- Languages (e.g., Python, JavaScript)
- Frameworks (e.g., Next.js, FastAPI)
- Tools (e.g., Git, Cursor, Notion)
- Soft skills (e.g., documentation, presenting)

---

## Certificates

- Certificate name, issuer, date, and link if available.

---

## Learning Notes

- Short notes on key concepts you learned.
- Links to helpful resources.

---

## GitHub / Contact

- GitHub profile link
- Email or preferred contact method
- Optional: LinkedIn or other links
