# Phase 6: Next.js Frontend

## Phase Goal
Build the user interface with **Next.js + TypeScript** — following **Figma (Phase 4)** and types from **Phase 5**.

## Key Concepts
- React components, props, App Router, layouts, forms, fetch preview.
- Frontend = UI; **FastAPI (Phase 7)** is the backend — not Next.js API Routes.

## Required Student Output
- Runnable Next.js project with `.tsx` components, layout, form, GitHub README.
