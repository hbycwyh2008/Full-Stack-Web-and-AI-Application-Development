# Set Up Your GitHub Repo

Your personal GitHub repository is your **learning evidence** for this course. It is **separate** from this course repository.

---

## Step 1: Create a GitHub Account

If you do not have one, sign up at [github.com](https://github.com).

---

## Step 2: Create Your Repository

**Required name pattern** (same course title as the teacher repo, with your name first):

```text
YourName-Full-Stack-Web-and-AI-Application-Development
```

Example: `LiMing-Full-Stack-Web-and-AI-Application-Development`

Use a hyphen `-` (GitHub does not allow `——`). Replace `YourName` with your
English name or school username. The class creates this **new public
repository in Lesson 3**, after the official repository video. Do not create it
early unless the teacher asks, and do not fork the teacher’s course repo.

---

## Step 3: Minimum GitHub Foundations Structure

Lessons 1–2 produce local notes. Lesson 3 creates the repository, and Lesson 4
uploads those saved notes. Continue building it gradually through all 15
GitHub Foundations lessons. By the end, it needs:

```text
YourName-Full-Stack-Web-and-AI-Application-Development/
├── README.md
├── learning-log.md
├── github-foundations/
│   └── lesson practice artifacts
└── mastery-check/
    └── final-github-practice.md
```

You will add more folders (projects, certificates, code) as the course progresses.

---

---

## Rules

**Do commit:** your notes, code, reflections, screenshots, certificates
**Never commit:** `.env`, API keys, passwords, `node_modules/`

**Commit messages should be meaningful** — they are part of your **revision record**.

Example: `Add profile/about-me.md` not `update` or `final`.
