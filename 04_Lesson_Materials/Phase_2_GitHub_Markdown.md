# Phase 2: GitHub + Markdown

## Phase Goal
Learn version control and professional documentation by creating your first GitHub repository with a complete README.

## Key Concepts
- Repositories, commits, and the basic Git workflow.
- Markdown syntax: headings, lists, links, images, code blocks.
- Why clear commit messages and documentation matter.

## Required Student Output
- A public GitHub repository.
- A `README.md` written using `01_Student_Templates/Project_README_Template.md`.
- A GitHub profile README using `01_Student_Templates/GitHub_Profile_README_Template.md`.

---

## Lesson Sequence

This phase runs over about two lessons (one week standard pace).

| Lesson | Focus |
|---|---|
| 2.1 | Markdown + first repo + README |
| 2.2 | Git workflow + profile README |

---

## Lesson 2.1 — Markdown and Your First Repo

**Lesson Goals:** Write Markdown and create a repo with a README.

- **Warm-up (5 min):** Show plain text vs. formatted Markdown. "Which is easier to read?"
- **Mini Lesson (15 min):** Markdown basics — headings, lists, links, images, code blocks (Resource #2).
- **Guided Practice (20 min):** Create a GitHub repo and add a README using `Project_README_Template.md`.
- **Independent Work (10 min):** Fill in Overview and Problem sections.
- **Exit Ticket:** Write a Markdown heading, a list, and a link from memory.
- **Homework:** Complete the project README; start GitHub Skills "Introduction to GitHub."

---

## Lesson 2.2 — Git Workflow and Profile README

**Lesson Goals:** Understand commits and create a profile README.

- **Warm-up (5 min):** "What could go wrong if you never saved versions of your work?"
- **Mini Lesson (15 min):** Repos, commits, push; live demo of create → commit → push (Resource #3, #4 optional). Show signing in with a token.
- **Guided Practice (20 min):** Students make 3 commits with clear messages.
- **Independent Work (10 min):** Create the special profile repo and add `GitHub_Profile_README_Template.md`.
- **Exit Ticket:** Explain what a commit is in one sentence.
- **Homework:** Finish GitHub Skills activity; publish profile README.

---

## Submission Requirements
- [ ] Public repo created.
- [ ] Project README follows the template.
- [ ] Profile README published.
- [ ] At least three meaningful commits.

## Common Student Problems
- Authentication fails → prepare a personal access token guide in advance.
- Vague commit messages ("update") → require messages that say what changed.
- Profile repo named incorrectly → it must match the username exactly.
- Forgetting to push → "saved locally" is not "on GitHub."

## Teacher Notes
> 强调清晰的提交信息和文档习惯。Emphasize clear commit messages and documentation habits. Authentication is the most common blocker — budget extra time and have a token walkthrough ready.

## AI Lens Reflection
