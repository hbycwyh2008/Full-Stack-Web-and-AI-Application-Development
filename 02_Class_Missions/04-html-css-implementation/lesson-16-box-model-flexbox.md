# Lesson 16 — Box Model and Flexbox

## Mission
Reason about layout instead of fixing spacing through random trial and error.

## Core Artifact
A responsive navigation or card section built with box-model reasoning and Flexbox.

## Launch Challenge — 0–10
Students inspect a broken layout and predict which box-model property is causing each gap/overflow before editing code.

## Evidence / Resource Scan — 10–25
Use one short reference on content, padding, border, margin, `box-sizing`, flex container/children, axis, gap, alignment, and wrapping.

## Team Sensemaking — 25–40
Teams annotate the Figma component: which relationships are one-dimensional and therefore good Flexbox candidates?

## Studio Build — 40–65
Implement the selected components. Students must use DevTools to inspect actual box sizes and flex behavior rather than repeatedly guessing CSS values.

## Critique / Test — 65–80
Partners deliberately change text length and viewport width. Record what breaks and why.

## Ship Evidence — 80–90
Fix one robustness issue, commit, and include before/after evidence.

## Success Evidence
Students can explain a layout using container/child relationships and the box model.
