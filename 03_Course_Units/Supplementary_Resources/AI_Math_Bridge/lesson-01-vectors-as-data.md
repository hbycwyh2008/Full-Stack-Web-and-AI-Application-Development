# Lesson 1: Vectors as Data

## Goal

Understand a **vector** as a list of numbers that represents real data.

## Key Ideas

- A vector is an ordered list of numbers.
- A student profile can be a vector.
- An image row can be a vector.
- Words or sentences can be represented as vectors in many AI systems (embeddings).

## Example

```text
Student A = [90, 85, 78]
Student B = [70, 95, 88]
```

These could be scores in different subjects.

## Activities
