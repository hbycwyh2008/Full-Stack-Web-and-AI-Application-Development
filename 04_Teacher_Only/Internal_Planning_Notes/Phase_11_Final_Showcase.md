## In-Class Learning Flow

### 1. Skill Warm-up
List your evidence chain: Git → Notion → Figma → code → reflections.

### 2. Talk Robin Round 1
- **You:** “The strongest evidence of my learning is…”
- **Partner:** “One thing I will demo live is…”

### 3. Entry Check
Name three rubric categories you will address in your talk.

### 4. Core Pattern
```text
rehearse demo → verify evidence links → present (live or recorded) → submit checklist → reflect
```

### 5. Guided Practice
Timed rehearsal; peer feedback on clarity and source display.

### 6. Independent Rebuild
- [ ] Fix last bugs yourself (debug log in reflection)
- [ ] Final README using template
- [ ] Notion page published
- [ ] Submission checklist complete

### 7. Talk Robin Round 2 + Evidence
Final Q&A practice; submit all links.
