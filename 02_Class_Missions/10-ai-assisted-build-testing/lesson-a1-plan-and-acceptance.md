# A1 — Plan a Testable Slice

**Length:** 45 minutes. **Evidence:** Three acceptance criteria and six test plans.

Use the [workbook](student-workbook.md) and [teacher guide](teacher-guide.md).

## 0–5 min — Skill Warm-up

Read the workbook example. Identify the input, action, and observable result. Use only a short excerpt of the assigned planning resource; full viewing is preparation.

## 5–9 min — Talk Robin 1

Explain the target user and main task from your prototype. Partner asks: “How would we know this works?”

## 9–14 min — Entry Check

Compare “the app works well” with “a blank title shows an error and adds no item.” Each student rewrites one vague criterion; share answers for diagnosis.

## 14–19 min — Core Pattern

Teacher models: requirement → Given/When/Then → test. Freeze one small feature and its success/error states before generating code.

## 19–30 min — Guided Practice

Create one GitHub issue and a feature branch before new files. Write three criteria and six test plans: normal, empty/invalid, boundary, state/repeat action, narrow screen, keyboard. Define a boundary (for example, 1 and 40 characters) and persistence behavior rather than assuming them.

## 30–40 min — Independent Rebuild

Without AI, write a criterion and a test for a new teacher-provided requirement. Partner must be able to execute it from your steps.

## 40–45 min — Talk Robin 2 + Evidence

Submit the workbook plan and issue link. State what you learned, one uncertainty, and the next improvement.
