# Module 2: HTML/CSS Digital Business Card

## Module Goal

Build a digital business card with HTML and CSS, then add it to the student GitHub repository and Notion portfolio.

Recommended time: **6 classes** of 90 minutes.
Fast track: **4 classes**.
Zero-background pacing: **8 classes**.

---

## Required Resource

[Learn HTML and CSS](https://www.coursera.org/learn/learn-html-and-css)

Key activity:

[Building your digital business card](https://www.coursera.org/learn/learn-html-and-css/ungradedWidget/hQxId/building-your-digital-business-card)

---

## Learning Cycle

```text
individual learning → Talk Robin / group discussion → group answer → Entry Points Check → teacher explains only what students do not understand → mission task → exit check → submission of evidence
```

---

## Suggested Class Breakdown

| Class | Focus | Evidence |
|---|---|---|
| 1 | HTML document structure | `index.html` with name, title, bio, and links |
| 2 | Semantic HTML and links | GitHub / Notion links working |
| 3 | CSS basics: colors, fonts, spacing | `style.css` connected to HTML |
| 4 | Card layout and visual hierarchy | Screenshot of card layout |
| 5 | Polish, accessibility, alt text | Improved version with meaningful commit |
| 6 | Independent rebuild and submission | Final digital business card evidence |

---

## Required Product

Students create a folder in their GitHub repository:

```text
html-css-digital-business-card/
```

Minimum files:

```text
index.html
style.css
README.md
```

Minimum page content:

1. Student name
2. Short learning identity statement
3. Skills started so far
4. GitHub repository link
5. Notion portfolio link
6. One course goal

---

## Independent Rebuild

Students must be able to rebuild a simple card without copying the Coursera screen:

1. Create a heading
2. Add a paragraph
3. Add at least two links
4. Connect CSS
5. Change color, spacing, and border radius
6. Explain one HTML tag and one CSS rule orally

---

## Required Evidence

Submit:

1. GitHub folder link
2. Screenshot of the digital business card
3. Screenshot or link showing commit history
4. Notion portfolio update showing the HTML/CSS card
5. One reflection: “HTML gives structure; CSS gives style because...”

---

## Success Criteria

Students are successful if:

1. `index.html` and `style.css` work together.
2. The card contains real student information.
3. The page links to both GitHub and Notion.
4. Commit history shows meaningful progress.
5. Students can explain the difference between HTML and CSS.
