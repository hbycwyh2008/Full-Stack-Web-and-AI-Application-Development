# Course Overview Collection

**Computer Science and AI Pathway**  
Chongqing Norin Bashu School for Children of Foreign Personnel  
Designed by Morgan Wang

---

## Capstone Course: Full-Stack Web and AI Application Development

A **portfolio-first**, **evidence-based**, **mastery-focused** course where students build real full-stack AI applications.

**Final project:** AI School Assistant — a document-grounded Q&A web app with sources.

### Learning Flow

```text
Git & GitHub → Notion Portfolio → AI Literacy → AI Math Bridge
→ Figma → TypeScript → Next.js → FastAPI → RAG Concepts
→ Full-Stack Integration → Cursor Capstone → AI School Assistant
```

### Course Philosophy

> This is not only an AI literacy course. It is an **AI application engineering** course built on top of AI literacy.

Students move from watching tutorials to **building, documenting, publishing, and explaining** real projects.
