# Phase 0: Git & GitHub

**Your goal:** Create your personal GitHub repository and use it as **long-term learning evidence** for this course.

**Open during class:** [Class Missions — 01 GitHub Foundations](../../02_Class_Missions/01-github-foundations/README.md) (one mission per session)

**Detailed setup:** [Student GitHub Repository Guide](../../03_Templates/Student_GitHub_Repository_Guide.md)

---

## What You Will Learn

- What GitHub is and why this course uses it for **learning evidence**
- How to create a repository, write `README.md`, and organize folders
- How to make **meaningful commits** and read **commit history**
- How to upload files, add code, and publish a small GitHub Pages site
- How to create, review, and merge a pull request
- How Issues and Projects organize work
- How profiles, accounts, and repositories stay secure
- How Markdown, forks, and contribution guides support collaboration
- Local workflow in VS Code: edit → stage → commit → push
- Difference between the **teacher course repo** and **your personal repo**

---

## Why This Matters

This is a **portfolio-first** course. Your GitHub repo proves **how you learned** — not only what you handed in on the last day.

Colleges, programs, and employers want to see **process**: commits, reflections, revisions, and projects over time. Phase 0 builds that habit before AI literacy and coding.

## In-Class Learning Flow

Follow your teacher’s timing. Each session uses the blocks below.

### 1. Skill Warm-up

**You do:** One official GitHub for Beginners video per lesson — **not** passive watching.

The playlist contains 16 videos. Playlist #10, GitHub Actions, is excluded;
the other 15 videos are taught in playlist order, one video per lesson.

- Note one reason people use GitHub
- Note one thing that is **not** enough to count as learning (e.g. watching only)

**Produce:** Two bullets in notebook or draft file before Entry Check.

### 2. Talk Robin Round 1

**Discuss with your partner** ([talk-robin-rules](../../02_Class_Missions/shared/talk-robin-rules.md)):

- How is this class different from a lecture class?
- What mastery level are you aiming for first?

**Be ready** if the teacher calls on you.

### 3. Entry Check

**You answer alone:**

- What will you build or document in this course?
- What is a commit?
- Name two types of learning evidence this course accepts.

### 4. Core Pattern

**Learn and write down today’s pattern.** Phase 0 patterns by session:

| Session | Pattern |
|---|---|
| 1 | version control → snapshots → Git evidence |
| 2 | status → add → commit → push / pull |
| 3 | create repository → README → commit |
| 4 | upload folder → verify path → commit |
| 5 | clone → branch → add code → stage → commit → push |
| 6 | branch → focused change → open pull request |
| 7 | review diff → merge pull request → verify target branch |
| 8 | professional profile → 2FA → private recovery information |
| 9 | issue → label → project status |
| 10 | secret scanning → Dependabot → security checklist |
| 11 | static page → Pages deployment → public URL |
| 12 | Markdown source → preview → rendered documentation |
| 13 | contribution rules → fork → contribution plan |
| 14 | VS Code edit → stage → commit → push |
| 15 | FAQ → final task → evidence → oral explanation |

### 5. Guided Practice

**You follow along** with class support:

- Create repo `YourName-Full-Stack-Web-and-AI-Application-Development`
- Complete the one guided practice named in the current class mission
- Commit with **meaningful messages** (not `update`, `final`)
- Open the relevant repository, issue, project, pull request, deployment, or commit view to verify evidence

### 6. Independent Rebuild

**You complete the checklist** without copying a full solution:

- [ ] Repo name correct; **your** repo, not teacher course repo
- [ ] Required files exist with **real content** (see Required Evidence)
- [ ] Meaningful commit messages
- [ ] You can explain your last commit orally

**Rules:** No AI full answer during this block. See [ai-use-during-practice](../../02_Class_Missions/shared/ai-use-during-practice.md).

### 7. Talk Robin Round 2 + Evidence

- Summarize today’s core pattern in one sentence
- Say what evidence you will submit in the last minutes
- Submit **Exit Evidence** before leaving (see class mission guide for today)
