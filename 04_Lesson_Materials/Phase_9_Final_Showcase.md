# Phase 9: Final Showcase

## Phase Goal
Deliver and present the completed AI School Assistant, with full documentation and a clear demo.

## Key Concepts
- Putting all phases together into one working product.
- Presenting technical work clearly to an audience.
- Demonstrating responsible AI use end to end.

## Required Student Output
- A working AI School Assistant (frontend + backend + LLM + documents).
- A complete GitHub repo with README.
- A Notion portfolio page for the project.
- A final completed Responsible AI Checklist.
- A live or recorded demo.

## Suggested Class Activities
- Practice demos in small groups with timed feedback.
- Prepare answers to likely technical questions (architecture, data flow, AI usage).
- Peer review using the Assessment and Presentation rubrics.

## AI Lens Connection
The showcase proves the course thesis: students do not just use AI — they understand it and build with it responsibly. Each student should clearly explain what they built versus what AI helped generate.

- [ ] Working AI School Assistant demo.
- [ ] GitHub repo with complete README.
- [ ] Notion portfolio project page.
- [ ] Completed Responsible AI Checklist.
- [ ] AI usage reflection and project submission form.
