# Optional Python 3 — Small Utility Project

## Mission
Build a small command-line or file-processing utility using the same lifecycle habits as the web project.

Students create an issue, define inputs/outputs, design simple cases, implement functions, test edge cases, open a PR, review, merge, and write a tiny release note.

Possible projects: text organizer, quiz-data checker, CSV summary, filename organizer using a safe sandbox directory, or study-note formatter.

## Evidence
A small reviewed Python project showing requirements → implementation → tests → release.
