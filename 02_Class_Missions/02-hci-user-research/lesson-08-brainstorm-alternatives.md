# Lesson 08 — Brainstorming: Generate Before You Choose

**Length:** 45 minutes  
**HCI stage:** Brainstorm / Design Alternatives  
**OMSCS CS6750 backbone:** **3.4 Design Alternatives**  
**Mission:** Generate many possible solutions to one evidence-backed need, avoid fixation on the first idea, and select distinct directions worth prototyping.  
**Durable Evidence:** [L08 submission template](student-templates/l08-three-alternatives-user-flow.md)

### Skill Warm-up video

| Field | Assign this |
|---|---|
| Primary | OMSCS CS6750 **3.4 Design Alternatives** — selected brainstorming / alternatives excerpt |
| Stop | **≤ 5:00** |

Bring one evidence-backed need from L07.

## 0–5 min — Skill Warm-up

After the OMSCS excerpt, answer:

1. Why generate alternatives instead of building the first idea?
2. What is design fixation?
3. Why should idea generation and idea evaluation be separated?

## 5–9 min — Talk Robin 1

State one evidence-backed need:

> **When ______, the user needs to ______ so that ______.**

Turn it into:

> **How might we help the user ______?**

Do not put a solution inside the question.

## 9–14 min — Entry Check

Decide which pairs are **genuinely different alternatives**.

Examples:

- list vs calendar;
- dashboard vs guided wizard;
- search-first vs browse-first;
- blue dashboard vs green dashboard.

Rule:

> **A new alternative changes how the user completes the task, not merely how it looks.**

## 14–19 min — Core Pattern

### Diverge first

1. Quantity before quality.
2. Do not judge while generating.
3. Build on ideas.
4. Push for structurally different approaches.
5. Do not let the first idea become the default.

Then converge:

~~~text
evidence-backed need
→ many ideas
→ 3 distinct directions
→ compare
→ choose one direction to prototype
~~~

Selection criteria:

- addresses the need;
- task is understandable;
- feasible to prototype;
- contains an important uncertainty worth testing.

## 19–30 min — Guided Practice

Individually generate **at least 6 rapid ideas**.

Then group related ideas and select **3 structurally different alternatives**.

For A/B/C show:

- start state;
- main interaction;
- 2–4 steps;
- success state.

Compare:

| Criterion | A | B | C |
|---|---|---|---|
| Addresses the need | | | |
| Main task simplicity | | | |
| Biggest uncertainty | | | |
| Feasible to prototype | | | |

## 30–40 min — Independent Rebuild

Choose one direction or deliberate hybrid.

Draw the primary user flow:

~~~text
Start
→ Action
→ State
→ Action
→ Success
~~~

Add one likely wrong turn and recovery.

## 40–45 min — Talk Robin 2 + Evidence

Submit:

- 6+ rapid ideas;
- 3 distinct alternatives;
- comparison table;
- selected user flow.

Exit statement:

> **“We did not choose our first idea automatically. We chose ______ because ______, and the main uncertainty to prototype is ______.”**

## Success Evidence

Students can separate divergence from convergence, resist design fixation, generate structurally different alternatives, and choose a direction tied to the evidence-backed need.
