# 00 — Course Culture, Computer Science Orientation, and Software Lifecycle

This unit begins with the **course culture**, not with computer science content and not with AP CSP.

Before students study **What is computer science?**, the AP CSP CED connection, GitHub, HCI, Figma, or programming, they complete a required 90-minute orientation built around the four official course posters.

## Required Order

### Required Orientation — Four Posters

[Learn the Course Through the Four Posters](required-orientation-four-posters.md)

Students first understand:

1. **Our Classroom Flow** — how every 90-minute class works;
2. **Mastery Level** — why completion or working code is not enough;
3. **AI Use Policy** — how AI may support learning without replacing thinking;
4. **CS Competition Pathways** — optional enrichment, not the definition of course success.

This orientation is a **prerequisite**, not an optional warm-up.

### Lesson 00 — What Is Computer Science? + AP CSP Discovery

[Lesson 00](lesson-00-what-is-computer-science.md)

Only after the four posters are understood do students broaden their model of computer science and complete a short AP CSP CED discovery activity.

### Lesson 01 — Product Teardown: Trace the Software Lifecycle

[Lesson 01](lesson-01-product-teardown-lifecycle.md)

Students then connect the broad discipline of CS to the specific software-development lifecycle that becomes the spine of this course.

## Why This Order Matters

```text
first: understand how this class works
      ↓
then: understand what computer science is
      ↓
then: discover how this course overlaps with AP CSP
      ↓
then: study how software moves through a full lifecycle
      ↓
then: GitHub → HCI → Figma → HTML/CSS/JavaScript → AI literacy → testing/release → capstone
```

The four posters are more immediately important to students than memorizing a definition of computer science or AP CSP terminology because they establish the behavior and evidence expectations used in every later lesson.

## Core Outputs

- four-poster evidence + course-culture claim board;
- CS field map;
- AP CSP preparation/gap map;
- software-development lifecycle model;
- first GitHub-ready learning evidence.

## Classroom Flow Requirement

All three sessions use the canonical [90-minute seven-block classroom flow](../shared/classroom-flow.md). Student activities and discussion drive the learning; teacher explanation is brief and diagnostic.
