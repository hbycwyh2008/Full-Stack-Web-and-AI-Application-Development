## Run Phase 0 First

1. Export [01_Student_Hub_Export/](../01_Student_Hub_Export/) to your Student Hub repo — share that with students on day 1.
2. Teach from [Detailed Lesson Plans — Phase 0](Detailed_Lesson_Plans/Phase_0_Git_GitHub/README.md) (80-minute sessions).
3. Students follow [Class Missions — Phase 01 Git](../03_Course_Units/Class_Missions/01_Web_Tools/Phase_01_Git/README.md) in class.
4. Grade Phase 0 with [GitHub Portfolio Rubric](../05_Assessment_and_Rubrics/GitHub_Portfolio_Rubric.md).
5. Supplement: [Git GitHub Unit](../03_Course_Units/Supplementary_Resources/Git_GitHub_Unit/README.md) — handouts, rubrics, parent overview.
