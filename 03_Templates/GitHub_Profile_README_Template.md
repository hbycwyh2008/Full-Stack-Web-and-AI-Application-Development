# GitHub Profile README Template

Your GitHub profile README is the first thing people see on your profile. Create a special repository named exactly the same as your username (for example, `your-username/your-username`) and add a `README.md` inside it.

Copy the template below and replace the placeholder text with your own.

---

```markdown
# Hi, I'm [Your Name] 👋

I'm a high school student learning full-stack web and AI application development.

## 🚀 About Me
- 🎓 Grade: [your grade]
- 🌱 Currently learning: Next.js, FastAPI, and AI app development
- 🎯 Goal: Build an AI School Assistant

## 🛠️ Tools & Skills
- Languages: Python, JavaScript
- Frontend: Next.js / React
- Backend: FastAPI
- Tools: Git, GitHub, Cursor, Notion

## 📌 Featured Projects
- [Project Name](https://github.com/your-username/project-name) — one-line description
- [AI School Assistant](https://github.com/your-username/ai-school-assistant) — my final capstone project

## 🤖 How I Use AI
I use AI tools (like Cursor) to help me write and debug code,
but I always test and understand the code I submit.

## 📫 Contact
- Portfolio: [Notion link]
- Email: [optional]
```

---

## Tips

- Keep it short and honest.
- Update the **Featured Projects** section as you finish each phase.
- Use emojis sparingly — they help readability but don't overdo it.
- Add a project only after it has a working repo and README.
